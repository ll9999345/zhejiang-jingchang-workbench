# 浙江文旅工作台设计约定

2026-09-30。根据用户确认的 Opus 原方案，将视觉方向升级为“暗房影院感”，全站 5 个页面一致调整。只重做表现层，不迁移后端、不引入 React、不替换生产流程。

## 信息结构

- 常驻侧栏：项目库、新建、五步制作、工具与设置、当前项目的素材剪辑与制作记录。
- 顶栏：当前所在步骤、搜索、主题。界面仅有一套导航，窄屏将同一组控件变成抽屉。
- 页面主区优先显示结果和下一步；技术信息放入展开项。
- 卡片代表作品、镜头或实际任务；避免为了排版把每段说明都装进大型圆角卡片。
- 既有项目编号保留在链接和详细信息中，主要显示项目名称。

## 视觉

| 项目 | 约定 |
| --- | --- |
| 字体 | 系统无衬线字体，中文优先苹方；无需在线加载字体；仅品牌“浙”字用本机宋体作为文化识别 |
| 浅色 | 宣纸灰白 `#f4f6f5`，白色面板，正文 `#16211f`，辅助字 `#5d6f6c` |
| 深色 | 暗房边界 `#0d1114`、内容底 `#141a1e`、卡片 `#1a2126`、浮层 `#222a30` |
| 主色 | 翡翠玉绿 `#4ade99` / `#7ee0b8`，深色主按钮 `#176b4d` |
| 层次 | 四级表面、多层阴影、边缘高光；常规圆角 8–18px |
| 材质 | 背景有低对比度渐变光场与细噪点；侧栏、顶栏、主要工作面和命令面板有分层毛玻璃；镜头/作品卡与编辑区保持更实的表面，确保清晰 |
| 间距 | 控件紧凑但保留分组间距；桌面主区边距 36px，窄屏 18px |
| 图形 | 自绘线性 SVG 导航图标；真实项目预览优先；不使用装饰性 emoji 图标墙 |
| 响应式 | 1100px 收紧布局；800px 以下改为导航抽屉；按钮窄屏至少 44px 高 |

深色主题默认走“暗房影院感”，新用户首次打开使用深色，已有用户选择仍从本地设置恢复。全屏背景纹理保持低对比，玻璃重点落在固定导航、主要工作面和浮层；方案/分镜/任务卡仍保留更实的内容底与足够对比度。卡片与主按钮允许细微边缘高光、玉色选中光和窄幅渐变；不使用大面积霓虹辉光遮盖内容。

统一令牌与共享外观覆盖在 `backlot/ui/theme.css`；导航布局、响应式规则和页面级精简样式在 `backlot/ui/studio.css`。各页面原有控制可见性的规则继续保留，避免把本来隐藏或被保护的生产按钮显示出来。

## 交互与动效

- 引入开源 Motion 12.23.24 JavaScript 运行时，本地随网页提供，不依赖外网 CDN。
- 步骤选中背景使用可打断弹簧，只改变 `transform`；重复的状态通知不会打断正在运行的动画，切换动作立即发生。
- 按压在指针按下时轻缩至 0.985；列表卡片轻微错峰淡入，悬停只抬升 1px 并增强阴影。
- 点击顶栏搜索时轻淡入并微缩放；Esc、关闭键和点遮罩有轻退场，选择命令则立即执行；⌘K / Ctrl+K 快捷开关立即响应。跨工作区切页用浏览器原生淡化衔接，当前步骤内容轻微上移淡入。
- 没有采用整页截图缩放过渡：本机验收曾出现缩放闪动，已移除。
- `prefers-reduced-motion` 下停用装饰动画、hover 位移与按压缩放；减少透明效果偏好下使用不透明表面。
- 导航不排队等待动画；浏览器返回恢复上个制作步骤；原工作流的阶段保护不改变。
- ⌘K / Ctrl+K：搜索当前页的功能与已有作品；匹配优先精确命中，并支持字符顺序模糊匹配；支持方向键、回车、Esc、焦点恢复。默认只展示最近 6 个作品，输入关键词后搜索全部。
- 支持常用别名：BGM/配乐→音乐、配音→旁白、搜素材→素材。搜索只打开对应位置，不执行生成。
- 手机导航打开时背景 `inert`，Tab 保持在导航中；关闭后返回菜单按钮。
- 本地存储失败不阻断主题显示；入口无法保存交接内容时明确提示，保留输入。

## 画布接入协议（9月29日约定，10月2日落实）

9月29日只提供了以下同源导航协议。10月2日已明确镜场目录并接入真实 `/canvas`，交换实现和边界见 [CANVAS_INTEGRATION_20261002.md](../CANVAS_INTEGRATION_20261002.md)：

```js
window.ZhejiangStudio.registerWorkspace({
  id: "canvas",
  label: "画布",
  href: "/canvas"
});
```

共享侧栏当前已注册自由画布，会携带当前 `project` 参数；扩展导航仍拒绝跨来源 URL。原生镜场界面由 `/canvas` 嵌入固定本机服务，不将其他地址注册为工作台扩展。

项目切换使用 `studio:project` 事件（`detail.id` 为项目编号，空字符串表示取消作品选择）更新扩展导航。资料交换另由 `canvas_bridge.py` 完成，原生保存／撤销仍由镜场负责。已确认镜头不自动双向覆盖；仅增加链接仍不能当作业务集成验收。

## 后续维护

新增功能优先归入现有五阶段或工具选择器；未经实际接线验证不显示可执行按钮。不要为每个上游开源项目再建一个重复主页面。保留真实报错与成本确认，让精简发生在展示层而非保护边界。

### 9月30日导航补齐

全站功能搜索直接打开实际工具或后期面板；没有当前项目时先在搜索浮层选择作品，避免落入空白新建流程。深链接恢复正确的可见面板，切换阶段会清除不相干的面板地址。后期单面板入场固定为220ms，不叠加列表错峰等待。
