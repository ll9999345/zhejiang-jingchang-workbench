## 五个制作阶段

### 1. 创意与脚本

- 免费估算与方案规划：三种创意、方案差异、评分、事实核对清单，质量优先或速度优先。
- 选定方案，再进入分镜；已有项目可以恢复、查看和修改原需求。
- 事实清单代表待核对事项，不能当成已经完成外部事实查证。
- 估算或规划不等于生成了视频，也不等于供应商实际扣费。

### 2. 分镜

- 各镜头的主题、时长、景别、运镜、画面提示、连续性与共享首尾帧安排。
- 分镜图生成与预览、逐镜修改与修复，随后人工确认。
- 从已选方案进入真实素材搜索或素材自动成片。
- 本轮改为先看镜头图片，展开单张卡片后再编辑细节；恢复项目时显示实际镜头数与确认状态。

### 3. 视频生成

- 使用原有模型选择、生成方式、时长、分辨率、画幅及费用上限。
- 保留“建立确认单 → 明确确认提交”的付费保护；导航和快捷搜索不会提交任务。
- 任务查询、取消、结果预览、本机下载与已完成片段恢复。
- 供应商任务完成、本地视频可用、质量验收通过是不同状态；本轮没有重新调用付费生成。

### 4. 后期制作

| 组别 | 实际用途 | 边界 |
| --- | --- | --- |
| 文案 | 脚本分段和原稿校对，保留后期输入 | 切换分类不清空；原稿不自动冒充真实转录 |
| 视频 | 选择实际视频、顺序与拼接参数，合成无 BGM 画面 | 必须有可读取的本机片段，输出不覆盖原片 |
| 音频：旁白 | 生成配音、导入或选择项目已有音频 | 提供者是否可用由本机环境决定；Piper 中文实测 |
| 音频：配乐 / 混音 / 精细调整 | 导入音乐或免费合成国风/电影/纪录片器乐，进入混音；音量、降噪等原音频处理 | 预设程序作曲不是自由提示词 AI 音乐模型；ElevenLabs 是明确选择的可选服务。声音、配乐、输入与混音结果分别保存 |
| 字幕：识别 / 校对 / 定位 | 从音视频真实识别，展示可校对分段；按已确认文字运行固定 WhisperX 中文定位 | 句级字幕与字级定位分开；精细模式主页面最多 120 秒，模型字典限制明确，不分离说话人；识别错字仍需人工核对 |
| 字幕：逐字高亮 / 下载 | 已保存字时间 JSON 接入原生 Remotion，导出带声音的真实 MP4；SRT / VTT / JSON 可复用 | 已在 Chrome 播放、下载和刷新恢复。只有句级 SRT 时估计时间明确标注；普通 FFmpeg 字幕不冒称动态逐字高亮 |

上述步骤在页内四分类切换；音乐/清理等旧深链接正确打开音频分类，字幕搜索定位到实际字幕面板。精细参数收起，不再把所有卡片同时铺满。已有转录刷新只读恢复，有未保存校对时保留本地输入，不重新识别或提交任务。

### 5. 验收与导出

- 对选中的最终视频进行实际媒体检查；关联选择的字幕文件与检查项。
- 保留质量记录、评分、交付参数、导出/下载及本机交付包。
- 技术检查与人工审美判断分别呈现；页面上有按钮，不代表该项目已经通过验收。
- 本地导出不等于已经向抖音、视频号等外部平台发布。

| 工具组 | 当前网页可操作内容 | 不应扩大宣传的范围 |
| --- | --- | --- |
| 离线抠图、人物增强与动画 | 图片抠图、人物眼部增强、Manim 中文标题/流程动画、Blender 三维标题图片、渲染已有 HyperFrames 工程 | Blender 底层能力清单较大，网页这个入口并非任意三维世界生成器；HyperFrames 渲染已有工程不等于自动写好任何动画 |
| 参考视频分析 | 本地视频镜头/关键帧与分析记录 | 不等于自主完成 Hypit 语义理解、工程编写和任意视频复刻 |
| 免费素材检索 | 沿用方案关键词、来源检查、检索下载、候选与来源记录 | 来源可能无结果、限流或拒绝访问；不能保证任意浙江具体地点都有公开视频 |
| 本地画面分析 | 抽帧、时间点/间隔采样、主体或人脸追踪相关检查与报告 | 降级路径应显示降级，不能将抽帧当作高质量人物跟踪 |
| 素材片段裁剪 | 输入片段、起止时间、输出与预检/执行 | 不覆盖唯一原件 |
| 节奏整理与画面增强 | 静音处理、速度、场景检测、重构画幅、调色等现有后处理 | 参数与输入有效性仍由原适配器检查 |
| 分镜图 / 素材 | 已接入的图像生成、结果与项目素材 | 外部服务需可用配置与授权 |
| 分镜图转动态视频 | 静态图的动态化处理、参数和结果 | 不能等同于高质量生成式视频模型的全部能力 |

## 真实素材自动成片

1. 承接当前选中的方案、脚本与镜头；修改正文后更新分镜。
2. 按镜头地点和画面意图整理搜索词。支持公开来源、本机素材或混合；通用氛围素材由用户明确选择是否允许。
3. 展示候选来源、缩略图和选片结果；可以导入视频、图片、旁白、配乐、SRT，调整镜头选片。
4. 设置旁白/字幕及画幅、分辨率、转场、音量等；本机声音与外部 Edge 语音有不同数据边界。
5. 自动搜集、初剪、按当前选片导出；查看进度、取消、历史任务与成片。
6. 高级设置包括字幕样式、配乐、版本组合、配置导入导出和已存在的扩展服务绑定。

素材搜集和视频制作本轮没有重跑；这里只验证了页面接线、已有项目恢复、只读能力与相关回归测试。检索质量必须结合具体主题、许可和真实候选复核。

## 核对入口与实现

`library.js` 负责项目库；`entry.js` 负责新建交接；`model.js` 负责五阶段及媒体工具；`footage.js` 负责真实素材流程；`board.js` 负责记录与回放。`studio.js` 只提供导航、外观与搜索，不接管生产动作。

本轮验收和运行边界见 `ACCEPTANCE.md`。后续新增能力时先更新本地图，再考虑新增页面，避免重新出现多个功能重复的创作入口。
