# 统一项目与运行说明

本仓库合并浙江文旅 AI 视频引擎 V2 与镜场 Agent 的源码和界面入口。原工作目录与业务数据保留；公开源码副本不带私人作品、账号、密钥、浏览器状态、运行日志和模型权重。

## 运行结构

一个主入口提供文旅页面和 `/canvas-module/` 镜场模块。Python 主服务负责文旅工具/API及同源模块代理；Node 子服务保留镜场工程、素材、任务与编辑逻辑。通过根目录启动器统一管理端口、目录和本次进程。两种服务属于同一源码仓库，并不意味着把两种工程的数据格式强制合并。

主服务默认4750，镜场4768。`--port` 与 `--canvas-port` 支持隔离测试。现有服务已占用端口时默认拒绝覆盖；只有明确选择 `--reuse-canvas` 才复用已核对的现有镜场服务，退出时不停止借用的服务。

## 原项目使用

可通过启动参数明确选择原文旅工程目录和原镜场数据目录；启动不会复制、删除或迁移它们。不要同时运行两个写入同一镜场数据目录的服务。已有4768实例可用 `--reuse-canvas` 保留其管理权。

统一入口应用玻璃视觉层，画布操作、创作台、云工作流、对话与工具页继续调用镜场本身的接口。减少动态设置、浏览器滤镜不支持和性能回退时使用静态表面。

## 可选运行时

- 基础：Python requirements、镜场 npm lock、FFmpeg/FFprobe。
- Hypit 兼容版源码位于 integrations/hypit/upstream；新版0.3.1固定源码运行时与依赖需要单独准备，未就绪时显示不可用。
- small/base ASR、中文CTC和隔离ML环境、CLIP、修复模型、Blender、GPU视频模型等不随仓库复制；按已有来源和固定版本说明准备。不要用一套机器的虚拟环境直接覆盖另一台电脑。
- CPU语音控制器只启动仓库固定程序，启用时保留工程原Profile。当前限制为已知纯本机配置、中文和每段30秒；宿主重启接管等仍需补齐。
- 云模型、RunningHub、ComfyUI、Flow等按各自入口的真实权限与协议配置。没有真实账号/GPU输出验证的功能仍按“待真实环境验收”标注。

## 验收记录

现有功能与历史边界分别见镜场 docs/FEATURES.md、docs/INFINITE-CANVAS-PARITY.md，以及本仓库相关技术文档。原镜场已发布0.99.24；本次源码另包含后续候选改动，本次快照及测试状态见 UNIFIED_ACCEPTANCE_20261031.md。不能把两边既有的测试总数相加当成一次统一项目全量验收。

统一启动器明确启用新版素材规则；直接运行镜场源码默认保留旧版规则。文旅交换服务在首次连接时确认规则，并在整个交换期间保持，规则变更时拒绝重交。旧工程不会因切换界面自动迁移。
