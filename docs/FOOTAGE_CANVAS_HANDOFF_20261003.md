# 真实素材初剪、免费配乐与画布接续

日期：2026-10-03。继续现有文旅工作树，保留原项目与未提交修改。

## 使用入口

1. 进入 `/footage?project=作品编号`，承接已选方案与脚本，沿用原有检索、选片和导入入口。
2. 音频栏选择 **免费合成本机器乐**，选国风、电影或纪录片预设。按实际旁白总时长生成并参加初剪混音，不需要 ElevenLabs。
3. 新初剪完成后点击 **在画布中继续剪辑**，确认带入该版选片、旁白和配乐，在原生「剪辑」视图继续调整。
4. 本机合成完成并加入当前画布后，**取回画布产物**，再到后期制作使用。

旧任务没有新增的 `canvas-cut.json` 记录，不会凭文件名补造编辑链接；按当前选片重新导出后才有链接，原 MP4 保留。

## 修改与实际实现

- `web_api/footage_pipeline.py` 接入现有本机器乐生成器：先锁定配音时长，后生成配乐，失败保留已完成配音。
- 新 `web_api/footage_canvas.py` 保存每版实际镜头、裁剪位置、时长、声音、字幕和 SHA-256 文件指纹；核对任务的已完成输出及文件字节后允许交接。记录不覆盖。
- `web_api/canvas_bridge.py` 按任务／版本独立关联，带入实际选片、入点／出点、画面适配、原声音量、逐镜配音位置与基础字幕。重复带入保留手动修改的镜头、对白、配乐音量；原分镜画布不混入初剪。
- 补齐 `.m4v`、`.ogv`、`.avi` 本机媒体类型；旁白只开放固定初剪任务目录的 WAV，不开放任意 artifacts 文件。
- 真实素材前端增加条件式音乐选项、经过核对的成片版本链接；设置恢复、配置导入／导出与批次保留选择。
- 画布前端显示版本、默认选择该版实际媒体并说明转换范围。手机关闭与确认固定可见，资料滚动。
- 相邻画布 `server.mjs` 只补充 `/public/native-workflow-config.js`、`/public/workflow-random-core.js` 两个现有静态模块地址，修复空白；其余并行开发代码保留。
- 画布健康检查允许本机助理配置冷启动稍慢，避免超过 2 秒就误报断线，等待有上限。

## 转换范围

- 画布采用直切；其他转场和静态图推拉仍保留在原 MP4。
- 基础字幕按镜头旁白建立；原 SRT 细分时间、字体和逐字样式再导出前核对。
- 配乐独立音轨保留音量；初剪自动压低配乐不直接复制，需试听。
- 每版单独编辑，不是原分镜自动双向同步。未勾选媒体不擅自绑定。
- 本机音乐为程序合成预设，不是自由提示词神经网络作曲。检索质量、AI 自主选片、完整 OpenMontage 导演与云端模型没有因此全部验收。
