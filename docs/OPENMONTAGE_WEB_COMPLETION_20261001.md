## 中文精细字幕与逐字高亮

1. 进入 **后期制作 → 字幕 → 已有录音或视频？自动识别字幕**，选择当前项目媒体和实际安装的 base / small 模型。标准定位为默认，中文精细定位为明确选项。
2. 识别后先核对下方文字。每行保留原字幕段；点击 **校对后做精细定位**，会把真实音频和校对文本带入原生工具表单，检查条件并确认后运行，不会自动执行。
3. 定位结果保存带字级时间的 JSON 和 SRT / VTT。点击 **用此字幕导出逐字高亮**，带入真实视频、已保存 JSON 和独立输出文件；再次检查并确认后导出 MP4。已有保存字幕也可从主页面的 **用已保存字幕做逐字高亮** 接入。
4. 刷新会读取磁盘中的原识别记录，不重新识别；有未保存校对时不覆盖输入。已完成任务可以播放、下载和继续使用。

这里的“精细定位”是把已确认文字对应到真实声音，中文按汉字定位；不是中文语义分词，也不会纠正识别错字。使用固定 WhisperX CTC 实现和本机中文 wav2vec2 权重，CPU 推理，不联网上传。时间来自模型对齐，不按文字长度平均分配；缺失时间不插值。模型分数是声音匹配分数，不能当作准确率。

主页面单次中文精细定位最多 120 秒；原生工具上限 600 秒、每段最多 30 秒，长录音需已有时间段。输入须与声音一致；字典不支持的发音字符（例如部分繁体字）、数字或外语会要求修正，不编造时间。低覆盖会失败，标点保留在正文；不提供说话人分离。真实 base / small 识别仍会产生同音错字，验收记录保留这些错误，正式交付须人工听看。

当前 Intel Mac 的 macOS 13 使用隔离的 Remotion 4.0.330 字幕运行时，输出包含声音的真实 H.264 MP4 和可编辑工程。原有 remotion-composer 4.0.484 与依赖保持；这次只验证该字幕入口，不声称全部上游复杂组合都已兼容。JSON 的真实字级时间优先；只有句级 SRT 时，估计词时间会明确标注。显式 FFmpeg 回退是普通字幕，不能冒称逐字动态高亮。

## 网页导演实际如何运行

1. 读取原生 `pipeline_defs`、阶段技能、Reviewer、Checkpoint 协议和 artifact schema。
2. 模型每步决定读取、写入隔离工程、保存阶段数据、调用工具、检查图片或完成阶段；没有通用 shell、系统安装或任意文件控制。
3. 第一次使用工具先读取其实际参数和技能；具体提供者固定，不能无提示改用其他服务。
4. 联网/素材传输、付费工具、录屏、工程源码渲染和远端视觉检查按具体动作确认。待确认阶段展示审核和实际产物下载。
5. 工具、新工程和原生检查点保存在独立目录；改写新工程时保留上一版本，当前项目原有成果保持。
6. 预算在调用前预留；价格不明的付费工具不会执行。缺模型、超预算、缺 artifact、不可播放的视频都不会标为完成。供应商账单仍以真实账号为准。

原生审核 schema 已补齐实际管线中的 research、proposal、character_design、rig_plan，以及 Reviewer 要求的 investigation、具体修正建议字段。阶段审核必须与当前阶段一致。

视频分析复用固定本机 CLIP 模型，避免 Python 3.13 主环境无法导入 Torch 时把整个功能误判为不可用。预检按实际模式检查条件；分类记录注明余弦相似度，不当作事实正确率。BLIP-2/LLaVA 只读取明确安装的本机 safetensors，不自动下载或切换模型。

## 模型配置

支持 OpenAI、OpenRouter、DeepSeek、豆包/火山方舟、Anthropic、本机 Ollama 与自定义兼容接口。这里的“支持”是请求协议接入，不是已验证所有账号和模型。

- `OPENMONTAGE_DIRECTOR_PROVIDER`、`OPENMONTAGE_DIRECTOR_MODEL`：可设置本机默认选择。
- `OPENMONTAGE_DIRECTOR_BASE_URL`、`OPENMONTAGE_DIRECTOR_API_KEY`：本机服务环境中的自定义地址和认证；网页不读取、保存或导出密钥。不要把秘密写入项目正文、截图、任务参数或日志。
- 标准提供者使用其对应的服务环境认证，例如 `ARK_API_KEY`、`DEEPSEEK_API_KEY`、`OPENAI_API_KEY`。
- 本机 Ollama 必须已有可运行服务和所选模型；仅填一个本机地址不能启动假任务。条件检查只查询本机模型目录，不调用生成。
- 远端模型需填写实际模型、官方输入/输出单价、总预算与本次数据传输/费用授权，然后检查；本轮没有替用户选择并付费开通服务。
