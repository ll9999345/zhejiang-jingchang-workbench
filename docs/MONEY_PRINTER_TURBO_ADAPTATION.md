## 早期适配历史（保留原记录）

本项目参考了 [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) 的任务编排思想，
没有把它的 WebUI、provider 配置或视频模板直接覆盖到 OpenMontage。两套系统的生产契约不同：
OpenMontage 需要三案选择、分镜/共享边界帧确认、付费闸门与证据质检，而 MoneyPrinterTurbo
更偏向“一键生成”流水线。

## 已适配到本项目

- 分镜图生成改为“先持久化 accepted 回执，再后台执行”的任务模型；
- 每个项目保存 `artifacts/storyboard_image_job.json`，记录任务 ID、镜头总数、已完成镜头、最后心跳、错误和最终回执；
- 页面通过状态接口轮询真实产物，不再用一个一直打开的 HTTP 请求假装“仍在生成”；
- 同一项目、同一镜头提示词和参数的重复点击使用 SHA-256 指纹去重，避免重复提交付费任务；
- 进程重启后可以读取已有回执；超过 3 分钟无心跳会标记为 `stalled`，不会为了避免重复扣费而自动重试；
- 保留其“脚本—素材—配音—字幕—BGM—合成”的阶段化思路，作为后续媒体管线的接入边界。
