# 本机 BGM 配乐入口

2026-09-16：默认入口改为导入已有本机音乐，不需要 ElevenLabs 或其他密钥。文件仅传入本机服务。支持试听、读取参考成片时长、循环/裁剪、末尾淡出和带入混音。此功能不是文字作曲。

新增 `web_api/local_bgm.py`，原音频与 MP3 均以唯一文件名存储，配套唯一来源清单及 SHA256。大小限制为 40 MB；ffprobe 检查音轨与输出时长。云端作曲仍在可选折叠区，原付费确认规则不变。

验证：独立临时项目使用非静音测试音频，通过实际 ASGI HTTP 导入接口产生 3 秒 MP3，HTTP 200、cost_cny=0；测试声音仅用于验证，不作为用户 BGM 交付。真实浏览器确认本机入口可见、ElevenLabs 默认折叠、从当前用户成片读取 26.857 秒。未代用户挑选音乐，未修改其成片。相关 Python 18 项、前端 26 项通过。

文字生成原创音乐尚未实现新的本机模型路线，需要另行确定生成服务或本机模型。
