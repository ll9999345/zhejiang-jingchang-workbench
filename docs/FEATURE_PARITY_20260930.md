# MoneyPrinterTurbo / OpenMontage 功能对照与本轮补齐

核对日期：2026-09-30；OpenMontage 接入更新至 2026-10-01。以本机源码、固定上游、实际页面和本轮输出文件为准。

## 结论与口径

两套系统的源码、工具注册、运行环境和网页接线不是同一件事。现有工作台原先有主要生产流程，但不能称为“两套所有功能均已在网页独立验收”。本轮补齐了实际缺口，并保留了仍需账号、特殊运行环境或 AI 编排的边界。

MoneyPrinterTurbo 对照固定的 **1.3.7 / e0c9cb77ffd0226a789441420190f80a125c20c4**；没有修改其上游源码。OpenMontage 对照本机工具与制作管线，网页使用已安装的真实工具和原生场景，而非只添加展示按钮。

状态定义：

- **本地实测**：实际执行并检查真实文件、时间轴、音轨或画面。
- **已接线**：网页与实际上游函数相连，参数/失败/确认有测试；不代表已做付费云调用。
- **Agent 编排**：工具、技能、阶段存在，需要 AI 助手策划、编写工程及审核；目录展示不能等同网页自主完成。
- **需配置 / 未验收**：缺少账号、授权、运行时，或本轮没有实际生成；不能宣传为全部可用。

## 用户入口

- 继续当前项目：`http://127.0.0.1:4750/model?project=项目编号`。
- 真实素材自动成片：全站导航中的 **真实素材成片**，或 `/footage?project=项目编号`。入口会沿用当前项目；没有项目时先选择或新建。
- OpenMontage：**工具与设置 → OpenMontage 制作室**，包含场景动画、长视频裁剪、完整原生工具和 AI 导演四种模式。也可使用 `#mediaMontageCard` 直接定位。
- 多服务、动态字幕等：真实素材页面顶栏的 **设置 → 扩展 AI 服务**。先选择用途与服务，再检查参数和执行。
- 中文精细定位 / 逐字高亮：主工作台 **后期制作 → 字幕**，识别后校对，交接至真实原生工具，检查并确认后生成；不会自动把 MoneyPrinter 的比例时间轴改成精细时间轴。
- 不恢复此前用户要求撤下的 Hypit 专页，不另建一套重复工作台，不把隔壁画布宣传为已接通。

### MoneyPrinter 原版操作布局

真实素材页面依据固定上游 `webui/Main.py` 的四列调用顺序和 `docs/webui.jpg` 调整：

1. 顶栏集中项目、任务管理和设置；全局导航成为默认收起的抽屉，释放表单宽度。
2. 日常控件依次归入文案、视频、音频、字幕四组；中等和手机视口分别为两列、单列。
3. 文案直接沿用当前项目，修改后可直接生成，自动更新镜头与搜索词；也可先更新分镜查看。旧选片不会在修改文案后被直接导出。镜头关键词、候选与选片移到下方默认折叠区域。
4. 底部统一以“生成视频”为主要操作，素材检索与选片导出保留为次操作；只制作声音或素材时，按钮明确显示对应阶段。
5. 历史任务进入任务管理弹窗；批量清单、设置导入导出、独立 AI 服务与高级剪辑进入设置弹窗。主流程与独立扩展的参数保持区分。
6. 快捷搜索优先定位本页音频、字幕等栏目；没有项目时可直接选择本机项目或新建，不自动提交制作。

这次调整沿用原控件与生产接口，原 98 个页面 ID 均保留。全局密钥备份、删除缓存等操作没有随着原版布局一起引入。

2026-10-01 完成该布局的补充验收：关闭快捷搜索和弹窗时正确恢复光标，执行栏目定位时不会被旧弹窗夺回焦点；参数错误同时显示在底部生成区，导入失败显示在设置弹窗内。描边小数值完整传给真实字幕渲染器，避免前端接受、导出却失败；音量输入步长与 0.18 默认值一致。免费规划进行中不允许再次提交制作。
