# Hypit 接入网页导演：实施与验收

日期：2026-10-02。对象是现有 OpenMontage 制作室；没有恢复已移除的 `/reference` 网页，也没有改动原项目素材和旧视频。

## 使用入口

在当前项目打开「工具与设置 → OpenMontage 制作室」，制作方式选择「AI 导演 · 完整制作管线」，导演制作方式选择「Hypit 参考复刻」。可以选当前项目里的视频，也可以导入本地视频，再填写改编需求。

参考视频分析卡片的「用这条参考片制作新视频」按钮会打开同一个导演面板并带入参考路径；不会自动提交模型请求。项目外的绝对路径只用于原有本机分析，进入导演时需要先将视频导入项目。

常用入口显示视频选择、导入和播放器。手填路径按需展开；切换项目会清空旧参考片，保留尚未提交的需求。修改参考、模型或需求会撤销原开始确认。

## 已接通的执行链

模型读取固定 Hypit Skill，结合真实抽帧、转录和图片检查理解参考片，再在独立目录创作 SVML/SVS/SVRun 及画面组件。工作区位于当前项目的 `analysis/montage/director/<session>/hypit-workspace`，重写源文件和组件元数据会保留前一版。

| 操作 | 当前行为 |
| --- | --- |
| 写工程与导入素材 | 只写隔离工程；素材复制后保存校验和，保留原件 |
| 注册画面组件 | 使用官方 `packages/<slug>` 加载约定；服务生成最小 ESM 包配置，不接受任意安装脚本或依赖配置 |
| Check / Plan | 调用固定官方命令；审阅源码及文件指纹，变更后旧确认失效 |
| Build | 官方 Plan 再次检查，只有明确列为本地的请求才会提交；保存真实 Build ID |
| Inspect / Get | 查询本次已登记 Build 的真实输出，为 Get 分配新文件，不覆盖原作品 |
| 交付 | 视频必须来自本次 Get；工程版本、视频校验和与实际媒体探测都要通过，未结束或未知渲染不能宣称交付完成 |
| 停止 | 区分停止导演观察与官方渲染取消；保留未知状态及编号，阻止重复提交。明确未提交的预检取消不会锁死后续任务 |

固定官方版本为 **0.2.12**，提交 `9c9918d0cedf2f06574ab0d517b1b6b0afb56a66`。公开 SDK 和 CLI 来自已安装的该版本，没有改写上游加载器或安装新的系统软件。

浏览器由服务端选择现有 Chrome 并写入固定本地 Profile；当前本机选中 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。管理员可用 `OPENMONTAGE_HYPIT_CHROME_PATH` 指定现存可执行文件。网页和模型不能提交 Runtime Profile 或浏览器可执行路径。

参考视频预览复用项目媒体接口，支持 HTTP Range 分段读取。缺少模型名等前置条件时，预检跳过所有可选工具的耗时探测；补好前置条件后仍会重新检查，不把未检查的依赖标成通过。

## 实际验收

- 后台联合回归 **174 通过**，另有 3 条既有 FastAPI `on_event` 弃用提示。包含默认模式、审批与指纹、组件加载配置、预检取消、未知 Build、防重复提交、工程版本绑定、产物被替换/丢失和参考播放器分段读取。
- 前端 **7 项单测与 8 组浏览器协议场景**通过，后者明确使用模拟 API；包括项目切换、导入、预览地址、确认失效、历史 Build ID 和缺条件阻止开始。
- 实际固定 CLI 已完成 **Check（三个 Source）→ Plan → Build → Inspect → Get**。官方 Plan 的 3 个请求均为本地，生成 **8 秒、540×960、30 fps、H.264/AAC MP4**；FFmpeg 完整解码退出码为 0，人工查看了 1、3、7 秒帧。
- 最终真实网页检查使用本机 4750 服务与既有项目，**没有模拟业务 API**。参考播放器实际返回 HTTP 206，读取到 58.909 秒视频并定位到第 3 秒；参考分析卡片可带入同一导演面板。1440px 桌面与 390px 手机均无横向溢出，手填路径默认收起，页面错误为空。
- 缺少模型名时的真实预检在 **575 ms** 内返回明确的 `needs_setup`；没有调用模型、导入视频或启动制作，没有更改原项目。该时间是本次本机实测，不是所有机器的性能保证。

真实命令回执：[receipt.json](../artifacts/hypit-director-integration-20261002/local-render-125757-71e42f/receipt.json)。这段视频使用固定官方 chat 示例检验工程执行与成品回收，**不是用户参考片的 AI 复刻作品**。没有调用导演模型、付费生成或云端制作。

首次新工程缺少组件、随后默认浏览器不存在的失败回执都保留在同一验收目录，没有抹去或把它们计作通过。

真实网页回执：[verification.json](../artifacts/hypit-director-live-ui-final-20261002-132748/verification.json)。截图：[桌面](../artifacts/hypit-director-live-ui-final-20261002-132748/desktop-reference-1440-loaded.png)、[手机](../artifacts/hypit-director-live-ui-final-20261002-132748/mobile-reference-390-fresh.png)。截图与第 3 秒实际媒体状态对应，原先的加载中截图仍保留；手机最终图使用独立手机视口复核，未将桌面缩放截图当成手机布局。

## 当前能力边界

初次本地渲染验收时没有填写通用导演模型名。同日后续已接入 DeepSeek V4.1 Flash，并通过真实官方鉴权和模型目录检查；网页默认选择 `deepseek-flash`，详见 [DEEPSEEK_DIRECTOR_20261002.md](DEEPSEEK_DIRECTOR_20261002.md)。参考片语义理解与自动编写新作品尚未进行实际计费制作，因此没有宣称「上传任意参考片即可自动得到合格复刻」已经验收。

工具或 Profile 显示可用属于依赖状态。上述官方示例证明本机工程渲染链能工作，不代表任意模型、复杂动画、账号、素材许可或作品审美已验收。Provider 的本地分类也不是 Node 代码的网络沙盒；工程执行仍保留源码审阅。

旧 OpenMontage、MoneyPrinter、后期制作和真实素材项目的既有成果保留。其他能力的先前验收边界继续以 [OPENMONTAGE_WEB_COMPLETION_20261001.md](OPENMONTAGE_WEB_COMPLETION_20261001.md) 与各自回执为准。
