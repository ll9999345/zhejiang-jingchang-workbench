# 画布创作助理 · DeepSeek 接入验收

日期：2026-10-03。范围：将现有官方 DeepSeek 配置接入镜场画布的创作助理与提示词改写，优化确认、预览与应用交互。没有重置工作树，没有删除旧页面、项目或素材，没有接着实现已暂停的参考视频复刻。

## 入口与实际用途

打开文旅工作台的「自由画布」，在右侧「创作助理」输入要求。当前实际服务显示 **DeepSeek V4.1 Flash · 已配置**，调用模型编号为 `deepseek-flash`。无需把视频发给 Codex，也无需在此重复填写密钥。

- **写剧本**：根据项目文字创作正文、角色或场景设定，作为新节点加入画布。
- **完善分镜**：追加分镜，或按现有镜头编号修改画面描述、字幕／对白、时长、景别、运镜及声音说明。
- **保留既有成果**：逐镜修改保留素材、配音关联和剪辑参数。替换全片分镜只有用户明确提出时才允许进入计划。
- **讨论与建议**：助理可以返回不含操作的回答，确认保存后留在项目的助理讨论记录中。
- **提示词改写**：提示词库的模型改写复用同一接法，先给出草稿；原文不自动覆盖。
- **免费工具**：整理画布与按段落拆分已有剧本在本机执行，不调用 DeepSeek。没有剧本时不会冒充生成完成。

当前助理仅理解文字及素材名称。它不会看到未发送的图片、视频或音频，不会自动付费生成媒体、下载素材或执行代码。独立对话、生图、视频节点以及 ComfyUI／云工作流仍使用各自已有的模型设置与执行确认，不因本次接入自动获得 DeepSeek 媒体能力。

## 使用步骤

1. 输入要求，或点「写一份完整剧本」「优化现有分镜」。
2. 检查模型、发送范围和费用估算；填写本次美元费用上限并确认。可选快速、稍作思考、深入或充分思考。
3. 助理返回后先展开修改项，检查时长、字幕、剧本正文等结果；尚未改变画布。
4. 点击「应用修改」。需要返回原状态时点击撤销；纯建议点击「保存回答」。

确认页明确包含：指令、项目名称与节点连接、节点文字、镜头设定、素材名称和最近最多 8 条助理对话。素材文件不发送。每个新模型请求都需要本次范围和预算，不会自动重试。费用估算按验证当日官方高峰单价、UTF-8 输入字节及最大输出量保守预留；实际费用以官方账单为准。思考内容也计入输出。

## 实现与配置

- 文旅侧：`web_api/canvas_director.py` 固定连接官方 `https://api.deepseek.com/chat/completions`；`scripts/canvas_deepseek.py` 提供私有标准输入／输出调用。
- 使用文旅工作台已选择的 CC Switch 中 Claude Code DeepSeek 配置，数据库只读。不是盲目读取 Claude Code 当前选中的任何供应商。
- 密钥仅在 Python 适配器读取并用于官方请求认证；不复制到镜场配置、浏览器、调用记录或文档。响应中的密钥形式也会隐藏。
- 镜场 `data/config.json` 只增加 `agentProvider: "deepseek"`；原有本机模型地址、ComfyUI 设置等保留。
- 请求编号、范围与输入摘要用于防止重复提交。开始请求前留存本机记录；重复点击、失败或服务重启不会自动产生第二次付费调用。
- 预览绑定当前项目修订及模型配置。画布或服务配置变化会要求重新检查；未完整结束、格式无效或超范围操作不会应用。
- Node 与原生 API 的原有修订检查、应用记录和撤销保留。新增 `edit_shots` 只改已有镜头文字与时长；不会替换媒体绑定。
- 原生分镜卡片现在直接显示对白／字幕，手机宽度下费用、范围与确认按钮可操作。
