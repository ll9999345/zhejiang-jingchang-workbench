## 当前限制

1. 免费素材来源的覆盖与可达性有差别，不能保证每个中文景点都有实拍。找不到时保留明确缺口，可换关键词、切换来源或导入自己的素材。
2. 选片相关性与地点真实性需要创作者检查；自动下载完成不等于景点核验通过。
3. 批量版本的变化来自同镜头候选与选片顺序。候选不足时可能产出相同版本，界面会提示需要补充素材。
4. Whisper 识别中的地名、专名需要校对。正式作品可优先走原稿配音与原稿字幕路径。
5. 外部服务需实际账号配置和执行授权后才能验收。预算确认不是服务商账单的技术上限；停止本机任务不保证撤销已受理远端任务。
6. 本轮使用短片验收功能与衔接，没有把七秒测试片当作省赛作品的内容质量验收。更长作品的节奏、配乐品质和选片丰富度仍须按具体作品审看。
