# 镜场网页素材采集

这是为镜场独立实现的 Chrome 扩展。它扫描当前标签页可访问的图片和直链视频，用户勾选并确认后将文件写入本机镜场的全局素材库；页面截图也能保存为图片。远程网页权限在导入或下载时按所选素材的域名请求，读取远程内容时不带网页 Cookie。

## 使用

1. 启动镜场本机服务，默认地址为 `http://127.0.0.1:4768`。
2. 在 Chrome 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，指向本目录。
3. 打开目标网页，点击扩展图标并连接本机服务，再点击“扫描当前网页”。
4. 可勾选“扫描前滚动加载懒加载图片”；需要扫描跨域 iframe 时，再勾选“扫描跨域 iframe”，扩展只会对当前网页列出的最多12个 iframe 站点请求可选权限。拒绝授权不会影响主页面扫描。
5. 勾选素材、设置分类后，可选择“导入所选”或“下载所选”。若要给导入的图片加语义标签，打开“导入后智能分类所选图片”，选择本机 API 设置中已保存的 OpenAI 兼容视觉对话模型，逐次填写授权信息并勾选本次发送同意后，点击导入。默认关闭时不会调用模型。
6. 点击右上角侧栏图标可在 Chrome 侧栏中保持采集面板打开。
7. 需要发现网页脚本加载的媒体时，先扫描，再点击“监听网络视频（60秒）”。Chrome 会申请网络监听权限及最多12个当前扫描已知来源；监听只针对当前标签页，并且必须保持采集面板打开。授权后播放或重新载入视频，结果会合并到采集列表。

只选择一份素材时会直接下载原文件；选择多份时会按网页标题创建 ZIP，并使用网页标题作为压缩包内文件夹。每批最多40份，素材总量上限为256 MiB；超限素材会显示失败原因，其余合格素材仍可打包。

素材进入镜场本机 `data/assets/`，分类为“网页采集”或输入的分类，可在工作台全局素材库中查找。扩展只向本机服务发送用户选中的二进制文件，不读取平台 Key。智能分类的可用平台/模型清单只返回名称、模型标识和服务来源，不含凭据；需要把 API Key 填在扩展弹窗中，密钥只保留在当前弹窗内存、不写入浏览器存储或项目文件。PNG/JPEG/WebP 且不超过10 MB的图片才会分类；每张最多发起一次请求。使用外部模型时需逐次填写单张预算和币种，但这是授权记录，不会限制供应商实际扣费。单张请求失败时会停止本批后续分类并继续本地导入；由于上游可能已经接收请求，扩展不会自动重试，建议先核对服务商任务和账单。

## 当前边界

- 支持网页 DOM 图片、SVG 中引用的图片、data URL 图片、可读取的 blob 媒体、MP4/WebM/MOV/M4V/FLV 直链视频、图片背景、可读取的 canvas 和当前可见区域截图；同源 frame 可直接扫描，跨域 frame 需用户勾选并批准对应站点（每次最多请求12个来源）。FLV 会保存为原文件，但浏览器未必能内嵌预览。canvas 仅导出不超过1600万像素且浏览器允许读取的内容；`blob:` 内容限制20 MB，单项最大150 MB。
- 网络监听只在用户点击后开启60秒，限当前标签页，并只读取获准站点的媒体响应 URL 与 `Content-Type`；不读请求/响应正文、Cookie 或鉴权头。可能带临时签名参数的 URL 只在扩展内存中保留，关闭面板即清除；用户未选中导入前不会发送到镜场服务。权限最多覆盖扫描时已知的12个来源，页面运行时新增且未获准的隐藏 CDN 请求不会被看到。
- HLS/M3U8 与 DASH/MPD 流媒体清单会被标记，但不会下载或合并分片；DRM、拒绝授权或受浏览器隔离而不可注入的 iframe、WebGL 实时内容下载、被跨域图片污染的 canvas 导出还未实现。受保护 canvas 可改用截图保存当前可见部分。扩展中的智能分类是明确选择后的图片语义分类，不会在扫描或普通导入时后台调用模型。
- 远程域名权限会在用户按下导入/下载时请求；拒绝权限时不会读取相应域名内容。数据只发到本机 `127.0.0.1` 或 `localhost` 镜场服务。

扩展代码由镜场项目独立编写，没有复制参考项目的源码或图标。参考的固定版本 Chrome 采集功能记录在 `docs/INFINITE-CANVAS-PARITY.md`。
