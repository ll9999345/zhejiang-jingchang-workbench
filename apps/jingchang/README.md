# 镜场 Agent

独立的本机影视创作工作台。以 GitHub Infinite Canvas 为主要功能基准，参考 LibTV、RunningHub RHTV，Miao 仅作交互借鉴，当前实现由本项目独立编写，不调用这些产品的 Agent。**尚未达到功能一比一对齐**，具体覆盖与缺口见 [功能对照](docs/FEATURES.md)。

当前源码与本机正式服务 **0.99.0**：原生智能循环新增明确的分支轮换开关，按真实坐标排序及起始计数/批次步幅选择，每轮只运行选中链，保留原连线；任务收据、原编号重启恢复、保护回填及v36工程/子图、v4整库保持该策略。923项自动测试、13组新功能Chrome、17组玻璃回归及6组正式只读检查通过。见[0.99功能与验证](docs/VALIDATION-0.99-2026-10-03.md)和[局部迁移范围](docs/NATIVE-BRANCH-PROGRESS-2026-10-03.md)。完整智能串联、嵌套及所有参考功能仍未完成，真实模型/GPU未验收。

答辩工作留痕已建档：[资料入口](docs/答辩资料/README.md)、[16张截图与图注](docs/答辩资料/截图总览.html)、[功能与技术](docs/答辩资料/功能与技术说明.md)、[实际工具](docs/答辩资料/工具与技术清单.md)。按里程碑保留来源、日志、增量补丁和验证范围，后续持续补充；首次建档仅整理已有证据。已有[0.97资料](docs/答辩资料/版本-0.97/README.md)，本轮新增[0.98资料](docs/答辩资料/版本-0.98/README.md)，新增[0.99资料](docs/答辩资料/版本-0.99/README.md)，含本轮截图、功能/技术说明和失败修复记录；旧资料和原件保持。还没有制作PPT文件。

主画布、创作台与对话页现已增量合并青蓝玻璃外观，保留弹簧按钮、拖动加粗滑条及原任务状态控制器。新增背景暂停、系统低动态、手机实底和一次性低帧率降级；34项相关单测及17组浏览器检查通过。截图使用独立Chrome软件渲染，手机和旧浏览器为模拟检查，未宣称实体设备或真实GPU验收；正式画布只读浏览，期间出现的并发画布更新和历史文件均保留。见[青蓝合并与截图记录](docs/CYAN-GLASS-MERGE-2026-10-02.md)。

## 打开

macOS 双击 `启动镜场.command`，服务启动后自动在 Google Chrome 打开 http://127.0.0.1:4768/。终端窗口关闭后服务继续运行；电脑重启后再次双击启动即可。要求已有 Node.js 22+ 和 Python 3。视频合成需要本机 `ffmpeg` / `ffprobe`。

也可以首次在本目录运行 `npm install --ignore-scripts --no-audit --no-fund`，随后运行 `npm start`。启动脚本会在缺少字幕组件时安装项目内依赖。`@napi-rs/canvas@1.0.9` 用于本机文字绘制，中文使用已有系统字体。不注册账号、不上传或部署站点。

## 建议流程

1. 创建项目，导入图片、视频、音频，或把 TXT / Markdown 拖入作为剧本。
2. 在画布添加文本、剧本、角色、场景与媒体节点。Shift 点击或 Shift 拖动框选，拖动标题移动选区；⌘/Ctrl+A 全选，D 复制，G 编组，Shift+G 解组，Z 撤销。
3. 本地 Agent 可以整理画布、按现有剧本段落拆分镜头。这是规则工具，**不会凭空创作**。在设置中接入兼容 Chat Completions 的本机语言模型后，自主 Agent 可以规划剧本、角色、场景和分镜，应用前显示完整操作计划。
4. 左侧「生成工作流」导入 ComfyUI **API 格式** JSON（不是界面布局 JSON）。在设置中管理自己的 ComfyUI 后端，每次运行可选择本机或已确认的局域网私有 IPv4 地址。修改参数，选择项目图片映射到 LoadImage / LoadImageMask、视频映射到 LoadVideo.file、音频或视频映射到 LoadAudio.audio，重复运行1–8次，或按提示词列表顺序运行1–64项。同一媒体跨字段/批次只上传一次。每次可递增 `seed` / `noise_seed`。需要所选 ComfyUI 已安装对应模型及节点；不自动安装，也未使用真实模型验收。
5. 任务中心查看状态。结果先留在全局素材库，点击「加入当前项目」才添加到画布；已编辑的目标节点不会被后台结果直接覆盖。中断后可查询原任务，不自动重交已提交任务。停止接收结果不等于停止 ComfyUI 内部计算。
6. 在资产页切换「当前项目 / 全部项目」，管理分类、标签、名称，跨项目复用；图片可按像素裁剪，视频可指定时间抽帧，原素材保留。提示词库保存并复用常用文字。
7. 分镜设置画面入点/出点、循环/定格、原声/配音及淡入淡出；剪辑页可添加背景声音、设置中文字幕。点击「预览 / 导出成片」检查参数后本机合成，预览与下载使用同一 MP4；另可导出 SRT、CSV、项目 JSON 和完整媒体备份。

## Midjourney（0.86）

在图片创作台的“连接设置”选择“APIMart Midjourney”，填写该服务实际提供的API地址和本次密钥；不会自动更换地址或复用火山密钥。模型参数中选择生成、2–4图融合、编辑，或放大/变体/重新生成/扩图/重塑；支持自定义宽:高，例如7:5。空提示词可用于融合和使用原任务的二次操作。

完成任务可保存1–4张图片、逐张下载或一起放入同一主画布。“基于此任务继续创作”只载入原任务编号与参数，再次提交仍需独立确认预算。局部重绘先选已放大的单图任务：提交重绘入口后，等待补参的任务有“补充重绘遮罩”按钮。选择镜场白色区域重绘遮罩或平台透明区域PNG，再单独确认第二次请求。停止查询或重启后只恢复原编号，不重新生成。

在普通画布的图片节点“绑定创作接口”里也能选择Midjourney，映射固定或本轮上游图片。等待重绘补参会停止后续节点；恢复仅查询原任务。完整备份按需使用v19，携带参数和参考图片；恢复不迁移密钥或执行授权，不发起生成。真实平台权限、版本、按钮支持、费用和画质仍需实际账号验收。

## 导入和托管大文件（0.85）

在素材库导入或将常见媒体拖入画布，超过150MiB时采用流式传输。也可打开“公网素材链接”，从电脑选文件，先点击“仅保存到本机”；完整文件保存在本机并通过字节数、文件头和内容校验后，才加入素材库。收到回复中断时只读取原记录，不自动重传。未完成的部分文件保留在`data/asset-imports/`，不作为可用素材；成功的暂存原件与素材共享同一文件，不重复占用一份空间。

选择temp.sh时，镜场允许单份最多4GB；选择Litterbox时本机接入上限仍为150MiB。预览和本机导入不会联系托管服务，另行确认原文件、目的地与公开范围后才单次发送。托管链接不延长模型时长、尺寸或输入字节限制，火山素材入库仍按实际格式及协议检查。

含大文件的完整备份使用v18，逐文件校验后在新项目恢复；v1–v17继续保持旧含义。备份不携带密钥、执行授权或生成任务，恢复不会自动上传素材。

## 共享文件夹（0.87）

素材库 →「共享文件夹」→「添加或重新启用文件夹」。填写项目目录内的子目录路径，或该子目录的完整路径。添加根目录、隐藏目录或符号链接会被拒绝；停用入口后，可以用原路径重新启用，源文件和导入记录均保留。

先按类型或名称筛选，点击文件名预览，勾选每批最多200份媒体并设置分类，再点「导入所选媒体到本机素材库」。单文件最多4GB，按原字节复制，不裁剪、转码或发送到云端。任务完成后点「将完成副本加入当前项目」，即可在素材库放到画布、下载或导出完整备份。BMP/MKV原件使用v20；其它备份仍采用其所需的最低版本。原件是否能播放取决于浏览器支持的编码。

窗口关闭后本机复制会继续；服务重启后，重新打开窗口或任务中心读取原记录。明确点击「继续未完成项」才会继续，完成副本不重新复制，收到的部分文件保留。若源文件已变化，请刷新列表并作为新批次重新选择。每次目录扫描最多8000个目录/文件条目，超限时可单独添加下级目录。

共享目录授权仅保存在当前工作区；完整备份只携带已加入项目的独立副本，不携带目录授权或复制任务。图片智能分类仍需在素材详情另行授权。此入口只供本机浏览，不开放局域网或公网访问。

## 独立素材库与分组（0.88–0.90）

素材页 →「库与分组管理」。新建独立素材库后，可建立媒体或工作流分组、修改显示名称、批量跨库移动、回收及恢复。媒体与工作流分组彼此分开。回收只是移出正常视图，文件和记录保留；至少保留一个有效素材库。原有全局素材、分类标签和项目关联继续可用。

媒体分组在「收藏已有素材」中勾选每批最多200份原素材，再点「收藏所选独立副本」。复制进度在「收藏记录」查看；关闭窗口不会停止。重启后读取原记录，明确继续才复制未完成项；已复制完成的条目不再重复。完成副本可加入当前项目，也能单独放入画布。主素材页可按独立库和媒体分组筛选。收藏保留原字节、现有标签和已经识别的图片分类，不自动调用视觉模型。

在画布选择节点后点「保存工作流」，默认保存**选中的节点**、它们之间的连线、分组成员和所需素材。依赖其它节点的绑定需要把来源一并选中。到工作流分组点击「插入当前画布」，追加独立节点和素材，保留原内容；可一次撤销或重做。关闭窗口后插入继续，复制期间的原有编辑保留。重启后打开「插入记录」，明确继续原编号；重复读取完成记录不会再次添加。下载`.jingchang`后，在另一镜场工作区的工作流分组中点「导入画布工作流文件」即可复用。

工作流分组仍可保存已有ComfyUI API模板的独立副本，或**整个当前项目**的画布快照。前者打开原有字段编辑器；更新模板后分组文件生成新快照，旧文件保留。后者可恢复为新项目。选中工作流使用v22，不包含未选节点、镜头、消息、会话历史或授权。保存、导入和插入均不会执行生成。0.90原生JSON/ZIP入口见下文；原生配置和执行语义不自动等同。

本机组织索引在`data/asset-catalog/catalog.json`，分组独立文件在`data/asset-catalog/libraries/`。跨分组移动会保留此前的文件；支持文件系统复制克隆时采用独立克隆，否则复制文件，因此磁盘占用可能增加。含组织关系或图片分类的工程备份使用v21：保留**该工程关联**的素材/绑定工作流所在的库、空分组及回收状态，导入时重映射编号。其它项目素材与库内整项目快照不递归打包；所有库的独立备份见下面0.95入口。

## 整库备份与恢复（0.95）

素材页 →「库与分组管理」→「整库备份」。点击「创建整库备份」，完成后下载`.jingchang-library`。它包含所有已保存独立库及媒体／工作流分组、空分组、回收条目、原始媒体、已有分类与标签、ComfyUI模板、完整工程快照和所选画布工作流。图片编辑、全景及增强的原图关系按需随包保存。未入库的当前工程请另用工程备份。

在另一镜场工作区选择文件，先「接收并检查」，查看库名称与数量，再「恢复为新增素材库」。新库、新素材和新模板重新分配编号，原库和当前画布保持；快照只作为库内文件保存，不自动新建项目、插入画布或生成。下载与接收都会验证文件长度、内容校验值和格式，损坏包不发布目录。

上传显示实际发送字节，文件处理显示已经保存的完成步骤；未知进度保持等待状态。关闭窗口后任务继续，服务重启后需读取记录并明确继续，已完成文件与已发布库不会重复恢复；被改过的现有文件不覆盖。上传回复丢失时先读取原接收记录，不自动重传。停止操作及未完成文件均保留。

这是镜场自有格式，不是Infinite Canvas原生目录包。每包媒体及画布文件内容合计最多4GiB，配置最多12MiB；库、分组和条目沿用当前目录数量上限。没有实际4GiB整库包或另一台实体设备验收。密钥、平台配置、生成任务、目录权限和未入库工程不打包；恢复不执行生成或访问第三方。

## MiniMax H3 分段时间轴（0.91–0.93）

在画布添加菜单选择「MiniMax H3 时间轴」，或从视频节点检查栏进入。可以先保存未绑定时间轴；需要生成时，在面板选择 ComfyUI 或 RunningHub，导入对应 H3 API JSON。RunningHub 还可填写站点与工作流编号，在确认查询范围后用本次密钥拉取整图和字段；查询不生成视频，完成后密钥清空。导入只保存在本机，按「检查并生成当前段」确认执行范围后才运行。

每段独立设置提示词、0.5–60秒时长、比例、百万像素和种子；参考最多9张图片、3段视频、3段音频。支持片段添加／复制／移出／重排、拖动起点和时长、撤销／重做、参考素材次序及跨片段拖动、播放头和静音、裁切入出点、历史结果选择与素材抽屉。同样的种子和输入可能命中 ComfyUI 缓存；需要变体时可换一个种子。

没有循环时，「生成当前段」仅规划该节点及相连上游。所属链包含循环时，入口显示「检查并运行完整画布」，先列出全部节点和轮次，再逐项确认；这会规划整个画布。停止／服务重启后继续原任务，不重新发送未确认的提交。加入项目时，未改输入的结果回到原片段；若修改了片段或上游，视频仍加入独立结果节点以供选择。导出裁切当前段或全部片段使用真实本机 FFmpeg，按顺序拼接裁切区间，使用项目画幅和帧率，不改现有项目分镜；全部导出需要每段都有本机视频结果。

RunningHub 模式使用云端整图已有的素材槽位，保留实际图片／视频／音频字段名，移除未填写的可选参考及仅被其占用的载入分支。每次生成前确认站点、预算、素材与整张工作流；预算是授权记录，不能限制平台实际扣费。PNG/JPEG/WebP 图片≤10MiB，MP4/MOV 视频和 MP3/WAV/FLAC 音频≤30MiB。切换引擎或解除绑定保留时间轴内容。

在画布添加「循环」并连到已绑定的 H3 视频节点，在循环设置的逐轮参数中选择 H3 专用字段。每轮可独立修改五项参数，原时间轴参数保持；时长变化仅作用于执行快照。列表模式要让片段提示词留空并启用上游输入，否则列表会被片段提示词遮住，预检会拒绝。明确映射种子时关闭 ComfyUI 的自动递增种子。仍沿用本机 repeat/list、1–32轮及整图最多64次执行的范围。

结果抽屉显示轮次和实际提交参数；「用于当前段」只选择视频，「采用此轮参数」才同时更新片段参数，保留后续片段间距，可撤销／重做。分次回填不会重复添加已接受结果；手动改输入或切换历史视频后，后续结果保留为独立节点，避免覆盖新编辑。每段最多100个历史视频，抽屉最多1000项；容量不足时保留现有历史与独立结果，不截断旧记录。请求参数不能证明真实模型输出的时长或质量。

本轮只使用本机协议模拟服务与真实媒体文件，未运行 H3 模型或远端 GPU。原生循环的并行、起始计数、图片批次、100轮和分支语义未等价适配，也未实现源项目的每次自动随机种子策略。真实 RunningHub 整图端点／账号权限及真实模型验收仍待完成。

本机 ComfyUI H3 使用 v24 `.jingchang` 完整备份；包含 RunningHub 整图或云端 H3 的工程使用 v25；含 H3 专用循环参数或逐轮结果记录时使用 v26。均保存尚未绑定的片段、参考、历史结果及抽屉；恢复会重关联素材、节点和云配置。选中工作流插入或复制时也重映射内部循环与结果关联。旧版本按原有含义继续读取。原生 JSON/ZIP 导出会拒绝已有镜场 H3 时间轴的节点，避免忽略已编辑片段；尚未迁移或编辑的原生 H3 仍可按原件导出。

## 原生画布文件（0.90）

素材 →「库与分组管理」→ 工作流分组 →「导入画布工作流文件」。选择 Infinite Canvas 原生JSON或ZIP，先点「接收与检查文件」；预览会显示全部节点、连线、分组、素材和待适配项。确认保存到此分组后，可「插入当前画布」，原内容保留。回复中断或服务重启后，可读取已接收原生文件，重新打开原预览。

普通/智能画布的v1文件、裸节点数组、嵌套workflow和UTF-8 BOM均可读取。ZIP中的原始图片、视频和音频按字节保留，原始参数可在节点检查栏查看。JSON未打包的素材会列为缺失；先导入素材，再在「补齐缺失素材」中明确关联。系统不会读取原电脑路径或自行下载地址。

普通生成节点需要检查原始参数、重新绑定本机工作流或平台，再勾选确认迁移。MiniMax H3 的 ComfyUI 和 RunningHub 模式可通过专用时间轴迁移；普通分组聚合、完整结果收集及整组输入已有迁移路径；ComfyUI和RunningHub媒体字段按明确序号选择一份素材，三类画布API可按各自能力传递整组参考。智能提示词可编辑字面分隔符、查看拆分预览，或在明确绑定及确认迁移后使用模型完整回答再拆分。关闭改写保留绑定但跳过模型调用。原生循环需在专用设置中启用；嵌套/分支和专用导演/增强与原生分组的组合仍待适配，未接入的组合会阻止运行。迁移成功的结果会保存为独立输出节点，并在输入/绑定未改时关联回原生源节点；运行期间的编辑保留。

分组条目可下载原生ZIP，所选节点也能从保存窗口导出原生JSON/ZIP。含本机素材用ZIP；原生导出保留原始编号，原编号重复时各份工作流分别导出。已迁移的本机配置用`.jingchang`保存，不能冒充等价的上游平台字段。含原生记录的选区和完整工程采用v23；旧v1–v22继续可读。

ZIP只接受未加密、已写本地头大小的Stored/Deflate及相应ZIP64字段，不接收数据描述符、未知条目、符号链接或损坏目录。配置≤12MiB，媒体≤1000份/合计4GiB；没有实际4GiB原生包或源软件运行验收。

## 新增原生协议（0.6）

## 统一创作台

画布顶部点击「创作台」，会关联当前项目；顶部「画布 / 分镜 / 剪辑」返回原项目。连接设置可复用「API 设置」保存的图片平台，密钥仍只在本次页面内存里使用。生成完成后点「放入画布」，结果进入同一项目、任务中心和素材库，可继续关联分镜、合成影片。

本次预算须独立填写并确认。视频按秒、图片按张估价；实际费用由上游决定。不会自动重发不确定的提交。当前验收使用本机模拟上游，未使用真实账号生成。

## 数据与边界

- 数据在 `data/`，包括项目版本、原始素材、配置、工作流、任务和合成文件。不要移除或覆盖此目录。
- 移出画布不删除媒体文件；撤销与历史恢复创建项目状态变化，旧历史保留。
- 项目 JSON 不包含媒体文件；跨工作区请使用「完整备份」导出 `.jingchang` 包，包含项目素材、关联工作流、创作台、对话、图片编辑和全景记录。原数据继续保留。
- 网页服务仅绑定本机，禁止其他网页跨来源调用。自主 Agent 地址限本机；ComfyUI 还可选择经用户明确确认的局域网私有 IPv4 地址。图片 API 可配置 HTTPS 云平台或本机地址，不接受重定向。工作流拒绝常见密钥字段；不保存访问密钥。
- 本机 ComfyUI 里的自定义节点可以具有自身的网络行为，工作台并不能隔离它们；请自行检查导入的工作流。当前验收仅使用模拟本机服务，没有调用云模型或付费服务。
- 画布连线可向直接图片 API 传递上游文字、参考图；ComfyUI 图片映射在工作流表单显式选择，可绑定到画布节点，按连线顺序自动执行并传递上游文字与首份图片。内置 LoadVideo / LoadAudio 及显式局域网后端选择已实现，其他插件字段和真实 LAN/GPU 仍待验收。
- 本地服务重启后，ComfyUI 任务保留原编号，可从任务中心继续查询；直接图片 API 不会在重启后重交请求；本地合成可按提交时保存的原剪辑重新运行，使用新的尝试目录，保留已产生的文件。未收到生成编号的提交不会自动重试，需先在 ComfyUI 核对队列。

- 拖动节点右侧连接点到另一节点左侧即可连线，也可以从左侧反向拖到上游右侧。原来的点选两端仍可使用。
- 拖动时预览连线并提示落点；松到空白处或按 Esc 取消。自身、重复、循环连接会被拦住。
- 右键空白处在当前位置新建节点；右键节点可编辑、复制选区、编解组、对齐、移出画布；右键连线可移除连接。选中多个节点后右键其中一个，会保留整组选区。
- 菜单支持上下方向键、Home/End、Enter 和 Esc，自动限制在屏幕内。拖线与菜单在窗口切换、缩放或窗口尺寸变化时关闭；节点移动在窗口切换或指针取消时结束并保留最后位置。
- 复制选区时，ComfyUI与云工作流引用的内部上游节点会改成新编号；外部引用保持原编号，需要相应连线才能运行。已有素材只复用引用，不改动文件。

## 宫格切分与图片拼接（0.15）

在素材库图片卡片点击「宫格」，或选中画布图片节点后点击「宫格切分」。设置行列、外边距和格间距，点击预览中的格子选择，再保存。最多8行8列，按左到右、上到下导出；不能整除的尺寸会分配到不同格子，不丢弃边缘像素。边距和间距内的像素按设置跳过。

素材库顶部或图片节点面板的「图片拼接」可以组合已有图片。调整图片顺序、每格尺寸、列数、边距、背景和适配方式；留边保留整图、裁满会裁切边缘、拉伸改变比例。支持透明背景和重复使用同一素材，末行空位使用背景。最多64张、8行8列，输出单边最多8192像素，总计1677万像素。

结果保存在全局素材库，可逐张下载、单张或全部放入画布；全部放入是一个可撤销操作。原文件不变。处理期间关闭窗口不会取消已经开始的本机处理，完成后从全局素材库找回。此功能使用本机FFmpeg，不需要API密钥。

## 画笔、遮罩与扩展边界（0.16）

在素材库图片点击「编辑」，或选中画布图片后点击「图片编辑」。支持画笔颜色、大小、硬度、不透明度；「擦除笔画」只擦除独立绘制层，原图不变。红色覆盖表示需要重绘的区域，可涂抹、擦除、矩形选择、清空、全选或反选。

「扩展画布」增加左/上/右/下透明边界，并自动把新增区域列入重绘范围；这一步不会凭空生成图像。可调整显示缩放，撤销/重做每一笔及扩展操作。

保存会生成三份本地PNG：编辑结果、白色重绘/黑色保留的黑白遮罩、透明区域重绘的输入图片。可单独下载、加入画布或全部放入。打开结果图片的「编辑」会恢复原图和已保存操作；再次保存创建新记录与素材，旧版本保留。结果面板可选择「以成品开始新编辑」，从合成图片开启新的编辑历史。

若使用本机ComfyUI，透明重绘输入适合LoadImage的MASK输出，或LoadImageMask的alpha通道；黑白遮罩使用LoadImageMask的red通道。选择已有重绘工作流并映射图片/遮罩后再运行。这里不自带模型权重，也不会自动提交生成。

编辑记录在`data/image-edits/`。从0.17起，完整项目备份包含关联编辑记录、原图、各阶段图像和遮罩；未保存的笔画只在当前编辑窗口中，关闭前请保存。

## 可编辑图片的完整备份（0.17）

导出项目时，只要其中素材关联图片编辑记录，备份就会自动收齐相关原图、编辑步骤，以及各阶段的图像/遮罩/重绘输入。即使项目里只有最终成品，恢复后也能继续编辑。只收录关联记录，不收录工作区中无关图片的编辑历史。

导入会为素材和编辑记录分配新编号，重新连接原图和输出关系。恢复后点击图片「编辑」，可以撤销已保存的笔画、继续绘制并另存；新旧版本分别保留。备份预览显示图片编辑记录数量。

带可编辑图片的新备份需要镜场0.17或更新版本；已有旧版备份仍可导入。旧备份本身没有的笔画记录无法补回，仍可把其中成品作为新底图。原图或必要记录缺失时会报错，请从备份恢复缺失文件，再重新导出。

## 360° 全景与截图（0.18）

导入宽高约2:1的等距柱状全景图片，在素材卡片点击「全景」，或在图片节点选择「全景预览」。拖动画面改变朝向，滚轮调整视野；方向键每次转动5°，按住Shift为15°。也可用滑杆调整水平、俯仰、画面旋转和视野，并一键切换前后左右方向。

设置截图宽高后点击「保存当前视角」，会生成真实的透视PNG图片，保存到素材库，可下载或放入画布。重新打开这张图片的「全景」会回到原全景图及保存的机位，可以继续调整。普通图片不会自动变成360°全景。

全景查看和截图完全在本机处理，不调用生成接口。完整备份会包含全景原图和视角；含全景视角的备份需要0.18或更新版本导入。原图保持不变。

## 在对话中生成与编辑图片（0.19）

进入项目「对话」，将模式切换为「图片创作」，选择已在API设置中保存的图片模型。可选择1:1、16:9、9:16、4:3或3:4比例，配合1K/2K/4K设置尺寸，也可直接输入`宽x高`或`auto`。实际尺寸支持由模型决定。

填写画面描述即可生图；编辑图片时可从项目选择参考，上传本机图片，拖入输入区，或粘贴到输入框。图片模式最多20张PNG/JPEG/WebP，每张不超过10MB。确认本次平台、内容与预算后发送一次；只发送当前描述和明确所选参考，不自动把整段历史发给图片接口。

结果直接显示在会话里，可下载、放回当前画布、点击「继续改图」作为下一次参考，或点击「讨论这张图」切回文字对话。后续文字对话会按最近20条完整消息收集文字和图片，需要支持图片输入的对话模型及对应发送授权。

图片保存到全局素材库；未放入画布的会话图片也包含在完整备份中。刷新和服务重启不会自动重新发起图片生成；取消仅停止本机等待。结果不明时需先核对平台任务和账单。

## 提示词列表批量生成（0.20）

打开ComfyUI工作流的运行参数，将「批量方式」设为「逐项提示词列表」，选择要替换的文字字段。可每行输入一条提示词，也可导入TXT；多行提示词使用JSON文字数组或导入JSON文件。最多64项，每项最多32000字，合计最多256000字。

列表项数就是运行次数；每项替换所选文字字段，其余参数共用，可递增随机种子。开始前检查整份列表和工作流字段约束，运行中显示各项状态、原任务编号与结果。同一参考素材跨列表项只上传一次。

「绑定此画布节点」会把列表保存到项目，刷新、复制和完整备份保留配置；顶部「运行工作流」可执行绑定的列表。整张画布仍最多32个生成节点、总共64次生成。下游节点取上游首份结果；本次列表功能还不等于整段多节点流程逐轮循环。

停止或中断后，可先点「仅取回已完成项」。继续原任务时查询已有编号，跳过完成项，再执行未提交项；已取回的图片不会重复加入。提交结果不明、没有原任务编号时不自动重做。工作流明确失败时，先取回完成结果，再检查失败原因。

每份结果回画布时保留对应提示词。目标节点已被你修改时，会创建新节点保留结果，不覆盖修改。需要实际ComfyUI模型、插件和算力；本地模拟测试不代表真实GPU生成已验收。

## 多节点循环（0.21）

画布底部「＋」添加「循环节点」，点击「设置循环」，可选择重复1–32轮，或填写每轮不同的提示词列表（每行一条或JSON数组）。从循环节点连到已绑定工作流的媒体节点；所有下游生成节点会组成循环体，每轮完整执行后再开始下一轮。整张画布最多64次生成。

列表文字需要工作流选择「自动传递上游文字」或云工作流绑定上游文字字段。下游每轮取得本轮上游的首份匹配素材；外部生成依赖只执行一次。开启递增种子的ComfyUI节点会跨轮递增。未改变参数的重复计算可能命中ComfyUI缓存。

顶部运行预览显示全部轮次。RunningHub每轮分别填写本次密钥、发送范围和单次预算。停止后可先「仅取回已完成步骤」，再从任务中心「继续原画布任务」；恢复查询原编号，不重新提交不确定任务。最终回填只加入剩余结果，原循环节点和绑定保留。配置和工作流可完整备份恢复。

暂不支持嵌套、重叠循环、条件分支、显式退出节点或把上一轮输出反馈到下一轮。不要把画布连成环；循环通过轮次控制执行。此版本通过本地模拟和浏览器验收，真实云账户及GPU模型仍需单独验收。

## 逐轮多字段参数（0.22）

循环节点连接并绑定下游工作流后，打开「设置循环」里的「每轮不同的参数」。点击添加，选择目标节点及字段，逐轮填写文字、数字、开关或下拉选项；同一循环最多16个字段。调整轮数会同步显示各轮输入框，已有值保留。

逐轮值覆盖该节点的固定参数，不修改模板。参数仍须遵守工作流的范围、步长、选项和隐藏设置；任一轮不合法都会在生成前阻止整批执行。媒体输入、上游提示词和提示词列表已占用的字段不能重复配置。显式指定每轮seed时，先在目标节点工作流里关闭「递增种子」。

运行预览逐轮列出参数。保存、刷新、整组复制、完整备份和中断恢复均保留设置；复制整组会让参数指向复制出的目标节点。当前逐轮参数用于ComfyUI，RunningHub仍通过循环列表接收每轮文字，其他云字段表格尚未覆盖。

## 图片API加入画布工作流（0.23）

选中图片节点，点击「绑定/编辑图片接口」，选择API设置中已保存的兼容图片平台、模型、尺寸和质量。文字可用本节点或所有上游；参考图可选相连上游的生成结果或固定项目图片，最多20张。此绑定与ComfyUI、RunningHub绑定互斥，保存时替换原绑定但保留原模板和素材。

顶部「运行工作流」现在可混合执行ComfyUI、兼容图片API与RunningHub。每个图片节点、每个循环轮次分别填写本次密钥、发送范围和单次预算。所有授权在任何节点提交前检查；没有确认不会开始前面的本机节点。绑定保存地址与模型快照，修改全局平台后重新绑定才会切换服务；完整备份恢复后也可直接使用快照。

同步图片接口没有可查询的原任务编号，中断或提交不明后不会自动重发。已完成的图片节点在继续画布时跳过；尚未提交的节点仍按原授权执行。普通画布现在也可在停止后「仅取回已完成步骤」，恢复完成后只补回剩余结果。

兼容图片使用上述绑定；语言模型和原生创作接口分别见下文0.24/0.25。验证使用本机模拟服务，没有真实云端付费或素材上传。

## 语言模型节点（0.24–0.78）

添加文本或剧本节点，填写本节点指令，点击「绑定/编辑语言模型」，选择API设置里的兼容对话模型或 Gemini 原生对话模型。可配置系统指令、输出上限，以及最多8张固定或上游图片、3份视频和1份音频参考。视频默认从开头每秒抽1帧、最多6张，不含声音；Gemini 可明确选用原视频，按模型文档启用后发送完整文件及其中声音，每份≤10MB。音频同样须明确开启 Gemini 音频能力。Gemini 使用完整返回；兼容对话可逐步显示。

连接到图片API、ComfyUI、RunningHub或另一个语言模型节点，顶部运行会按顺序执行。下游文字映射使用本轮生成的完整回答；原节点指令保留，结果另外生成文本/剧本节点。语言模型也可单独运行，或加入循环。每个节点、每轮分别确认文字、图片、视频抽样或原视频及声音、音频范围与预算，密钥不保存。

断流、输出被截断或返回工具调用时，已接收文字保留查看，下游停止；不会把未完成片段当完整回答，也不会自动续写或重发。后续可恢复任务中断时，已完成的语言模型节点直接跳过；文字结果和媒体结果都可分次取回且不重复。绑定、组复制及完整备份保留模型快照和参考映射。

当前支持 Chat Completions 兼容和 Gemini 原生语言协议，不执行模型返回的工具指令。Gemini 原视频/音频输入经本地模拟服务验证，尚未验证真实理解质量；大文件远端上传、其他原生语言协议和自动质量评判仍未齐备。


## 原生图片与视频接入画布（0.25）

选择图片或视频节点，点击「绑定/编辑创作接口」，可复制本项目创作台的参数，或填写服务地址、协议、模型和生成参数。复制不带入创作台自己的提示词，画布使用当前节点及选定上游的文字。保存地址与参数快照，之后创作台的修改不影响已绑定流程。

视频支持创作台已有的通用文字/单图生成、单视频编辑或续写、方舟文字/首帧/首尾帧、APIMart已支持的Seedance文字/公网首尾帧。图片支持通用同步/异步、ModelScope异步与LoRA、原生Gemini、APIMart异步图片。支持范围沿用各协议的已有实现，不表示平台全部模型通用。

参考素材可选固定项目文件或相连上游本轮的生成结果，按界面顺序传递；方舟参考1是首帧、参考2是尾帧。APIMart视频只接受公网HTTPS图片URL，不会自动上传本机文件到图床。语言模型的完整回答可作为提示词；创作接口上限5000字，超长会停止下游，不静默截断。

可与ComfyUI、RunningHub、兼容图片和语言模型组成混合流程、加入循环。逐节点/逐轮确认发送范围和预算；参考单价已填写时校验预算不少于估算。视频及异步图片持久保存原任务编号，页面显示进展。停止、重启后查询原编号，已完成步骤跳过；没有编号的同步请求或不确定提交不会自动重发。从任务中心点击子任务会打开所属画布流程。

结果可分次加入项目，保留原节点和绑定；整组复制重映射动态素材，完整备份导入空白工作区后仍可执行。所有新链路仅做本机模拟协议及真实媒体播放验收，尚未调用真实付费服务，也未完成全部参考项目的功能整合。

## 剪辑与成片（0.26）

在「分镜 → 编辑」中设置镜头时长、视频入点/出点，选择片段不足时循环所选区域、停在末帧或提示调整。画面可完整显示或居中铺满；配音支持独立入点、延迟和音量，原声可保留混合、自动关闭或静音。镜头声音可淡入淡出。

在「剪辑」页添加最多16条背景声音片段，设置素材入点、成片位置、时长、音量、循环和淡入淡出。背景轨不跟随镜头移动；重排或缩短镜头后请检查声音位置。

「声音与字幕」可启用中文字幕写入画面，并设置字号、文字颜色、描边、底边距和底板浓度。每个镜头的对白按实际帧数对齐；过长字幕自动缩小/换行，仍无法容纳时会提示拆分。导出另提供同一版本的 SRT。

点击「预览 / 导出成片」，检查媒体时长和声音范围后开始合成。预览、播放和下载使用同一份 MP4。任务可停止，重启后按**原提交设置**重新合成；要使用修改后的设置请新建导出。成片可直接下载，也可点击「加入素材库」回到原项目与画布，重复操作不会重复加入。单个入库文件限150MB，超过时仍可直接下载。

当前为顺序镜头 + 独立背景音频片段，输出 720p（竖屏为720×1280），支持24/25/30/60帧。多画面叠加、镜头转场、变速、逐词字幕时间和剪映工程尚未实现，也不等于 LTX Director 专用工作流。所有本轮验证使用本机合成媒体，不调用生成模型。

0.26 验收补记（2026-09-29）：本地剪辑、混音、中文字幕、原快照重做与成片回填通过194项本地测试和27项浏览器检查，既有80个数据文件未变化。详见 [0.26验收记录](docs/VALIDATION-0.26-2026-09-29.md)；全功能复刻与真实云/GPU验收仍未完成。


## 图片角度 / 导演机位（0.27）

在图片节点点击「图片角度 / 导演机位」，或在素材库点击图片的「机位」。选择或导入 PNG/JPEG/WebP 参考图，调整水平角（−90°～90°）、俯仰角（−90°～90°）和距离（0.1～8，默认4）。支持拖动、方向键、滚轮、快捷景别和逐项重置，补充提示词保留原文。

平面透视预览用于观察机位关系，不代表三维重建或生成结果。保存后得到独立的机位图片节点；修改角度只影响下次执行，原图保留。节点与原图引用一同保存、复制、撤销和备份。运行时会把角度转换为明确的镜头指令，和参考图一起交给生成服务。

## LTX 导演时间线（0.28）

画布「＋」菜单选择「LTX 导演时间线」，或在视频节点面板打开同名入口。

1. 导入自己已在 ComfyUI 配好模型与插件的 API 工作流，选择其中的 `LTXDirector` 节点。参考图引导还需要与其 `guide_data` 相连的 `LTXDirectorGuide`。

3. 以秒或帧设置起点、时长、提示词和图片参考强度。拖动移动/裁切片段，在播放位置切分，复制片段或撤销重做。音频可设置源素材入点；运行前会检查实际音频时长。

## 细节增强与 2K / 4K 放大（0.29）
