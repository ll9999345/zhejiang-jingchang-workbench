# 0.52 验收记录：图片预览缩放和平移

日期：2026-09-29。浏览器使用隔离数据目录与合成图片；没有对现有项目或素材写入。

## 实现

- 图片预览可在 100%–600% 之间滚轮缩放，缩放以鼠标指针所在位置为锚点。
- 放大后可拖动平移；平移手势不会被误识别为切换上一张/下一张。
- 双击或使用带无障碍名称的复位按钮恢复原始倍率与位置。
- 保留原有方向键、触屏低倍率滑动、视频播放控件和批量下载。

## 验收

- `node tests/media-viewer-zoom-browser.mjs`：5 项检查通过，覆盖锚点、100%/600%边界、拖动后不切片、双击复位与按钮复位。
- `node tests/media-viewer-browser.mjs`：13 项既有浏览器回归通过，包含手机视口/滑动、图片视频浏览、ZIP 下载和重新生成授权表单。
- `npm test`：全量测试通过。
- `npm run check`：全部语法检查通过。
- 浏览器无页面异常；测试运行在本机隔离数据目录，不配置服务商，也不产生外部请求。

## 边界

本次仅完成参考预览中的图片查看交互。没有实现触屏双指缩放，也没有连接真实模型、ComfyUI、RunningHub 或其他平台。Infinite Canvas 整体功能仍未完全复刻。
