# 0.26 本地剪辑与成片验收

日期：2026-09-29。范围为现有自建镜场项目的剪辑/混音/字幕/导出整合，不是整体功能复刻完成。

## 交付

- 分镜可设置视频素材入点与出点；不足时循环所选片段、末帧定格或拒绝。图片/视频支持完整显示与居中铺满。时长可填小数，并按帧率对齐。
- 原声可保留混音、配音时自动静音、始终静音。独立配音支持素材入点、镜头内延迟及音量；镜头声音淡入淡出。
- 16条以内的背景音频片段：位置、素材入点、持续时间、音量、循环、淡入淡出；不改变原始媒体文件。
- 中文硬字幕：字号、颜色、描边、底边距和半透明底板；按镜头显示、自动换行/缩小，过长则报错。MP4和独立SRT使用同一份剪辑快照和实际帧时长。
- 预检查、稳定请求编号防重复、版本冲突提示；停止后及服务重启后按原快照重新合成，新的attempt目录保留旧尝试。预览与下载使用同一真实MP4；完成结果可幂等回填原项目的素材库和画布。
- 剪辑设置/背景音频随完整备份迁移，导入后重关联素材并能继续合成。Mac常见M4A、浏览器WebM音频输入可用；无时长头时流式扫描时间戳，不按文件大小猜时长。

新增免费项目依赖 `@napi-rs/canvas@1.0.9`，位置为本项目 `node_modules/`，版本与完整性信息在package-lock.json。未安装系统软件/字体，使用本机已有PingFang SC。启动脚本缺少该项目组件时会安装npm依赖（禁用安装脚本），现有组件可正常载入。

## 已修正的实际问题

1. 旧时长输入步长导致0.75秒镜头无法保存：放开小数输入，统一按帧对齐。
2. 导出接口对过期版本的异步异常没有在请求处理中等待，导致进程退出：改为正确等待并返回409，浏览器复测无退出。
3. 无时长头WebM不能进入合成计划：增加仅本地格式/协议的增量时间戳扫描，并实际混入MP4验证。

## 边界与待办

- 顺序画面轨 + 独立背景声音片段；尚无视频转场、变速、多画面叠加、逐词字幕时间和剪映工程。
- 本轮没有实现LTX Director专用工作流、3D导演台、CLI或浏览器/Photoshop连接器。已有生成协议的其他缺口仍见功能对照表。
- 合成上限1–100镜头、单素材150MB，固定720p级画幅与24/25/30/60fps；超过150MB的成片可直接下载，但不回填素材库。旧版无快照导出记录不能按原设置恢复。
- 只验证了本地媒体处理与既有模拟协议；没有付费调用、第三方素材上传、真实云账户/GPU或生成质量验收。日常服务agentConfigured=false，不能声称自主语言模型已可用。
