# 0.58 验收记录

日期：2026-09-29  
范围：Infinite Canvas 固定提交 `67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e` 的 Chrome 素材采集行为。本记录覆盖 0.57 本机导入接口和 0.58 SVG/canvas 扫描增量，不代表全部上游功能已复刻。

## 实现

- 新增独立编写的 Manifest V3 Chrome 扩展，扫描普通网页图片、常见视频直链、CSS 背景、SVG `<image>` 引用和可导出的网页 canvas；提供懒加载滚动、当前可见视口截图、所选素材下载或导入本机镜场全局素材库、侧栏入口及手动分类。
- 远程域名权限按用户选中素材申请，抓取不携带网页 Cookie；扩展只向 `127.0.0.1`/`localhost` 的镜场服务提交所选文件。
- 新增扩展来源限定的 `/api/chrome-import` 接口，限制 MIME、文件大小和素材分类。未保存来源网页地址、凭据或 API Key。
- 可读取 canvas 限制为不超过 1600 万像素且不超过约 20 MiB；被跨域内容污染、超过上限或 WebGL 无法导出的画面需要使用视口截图。单个 blob 上限 20 MB，单文件总上限 150 MB，每批最多 40 项。
