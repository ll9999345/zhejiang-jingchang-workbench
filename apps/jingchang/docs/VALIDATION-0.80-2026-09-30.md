# 0.80 验收：本机 CLI 版本与帮助

日期：2026-09-30。

## 本轮交付

- 设置和诊断新增本机工具面板，列出 Codex、Gemini/Antigravity、即梦的程序查找结果。打开面板及原状态接口仍不执行 CLI，安装不等于登录、可生成或账户已开通。
- 用户点击后可查看一次版本或白名单主题帮助；Codex/Gemini/Antigravity使用 `--help`，即梦使用 `-h`。登录、安装、积分和生成主题也只显示说明，不执行相应操作。Gemini与Antigravity按实际解析的程序和显式配置区分。
- 后端只接受固定参数，不经shell，不接受用户提供的可执行路径、脚本、提示词或任意参数。子进程只继承必要系统环境，不传入父进程的 API Key 或 `NODE_OPTIONS`。标准输入关闭，版本10秒、帮助20秒超时，最多64KiB合并输出，同时只读取一个信息请求。
- 常见凭据形态和终端控制码过滤后以纯文字显示；失败不返回原始错误输出、不自动重试。关闭面板停止本次等待并清空显示，POSIX取消本次创建的进程组；结果不写入业务配置、项目、任务或日志。
- Windows `.cmd/.bat` 和WSL入口仍只检查存在性，版本/帮助尚未执行；返回明确不可用状态。缺少程序时不会自动安装。

## 验证结果

- 全量 `npm test`：398/398通过；最终语法检查通过。新增9项 CLI 信息执行、固定主题、环境、错误/超量输出、超时/取消、同组子进程终止、单次运行和不支持入口测试，保留原4项状态检查。
- 最新本机工具浏览器12项通过：设置/诊断入口、打开零执行、连续点击只运行一次、主题只显示帮助、纯文字/复制、输出过滤、失败及后续重查、参数与跨来源拒绝、手机布局、关闭清空与取消、服务重启后区分Gemini、缺失程序禁用、业务数据无结果/凭据落盘。程序均为隔离合成可执行文件，网络只允许本机。
- 既有图片API浏览器10项回归通过：模型设置/发现、生成/参考及原生遮罩、任务结果、密钥不落盘、诊断、手机、项目回收恢复。合计22项浏览器检查。
- 正式服务真实检查本机 Codex：`codex-cli 0.147.0`，主帮助正常返回，`loggedIn:null`、`accountChecked:false`；只记录版本、返回长度和命令参数，不保存完整帮助。
- 正式服务 `/api/health` 返回0.80.0、`agentConfigured:false`、`model:null`，正式任务0。原有85份业务文件逐份SHA-256不变，无新增正式业务文件。

全量测试初次有一项取消测试误判：80ms或固定100ms等待会在大量并行任务时早于模拟程序开始记录。改为等待实际启动记录后测试取消，允许超时发生在启动记录前，仍确认不自动重试；完整复跑通过，没有放宽取消或超时要求。
