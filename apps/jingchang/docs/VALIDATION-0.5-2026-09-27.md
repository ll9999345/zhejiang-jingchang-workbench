## 已完成的新增链路

- 独立对话页与项目关联：会话创建、历史、改名、图片上下文、平台/对话模型选择、明确单次授权、答复回填原画布；图片以真实文件内容传送，密钥仅用于本次请求。
- ComfyUI 画布执行：生成节点绑定模板与持久参数；按连线依赖顺序运行，传递上游文字和新生成图片；失败停止后续节点、取消与原任务恢复、结果统一回画布。至多 32 个生成节点、64 次计算；不自动重提不确定任务。
- ModelScope 原生异步文生图：固定协议请求头、提交/查询、LoRA 权重校验、结果下载与项目回填。暂不覆盖图片编辑及模型全部参数。
- 方舟原生视频：文生视频、首帧、首尾帧；本地图片转换为请求数据，任务查询、原编号恢复、结果下载。未实现平台素材库或视频/音频多参考。
- 修复恢复任务时先读取到旧取消状态的竞争问题：先持久化运行状态再启动恢复。

## 正式本地服务与数据

升级前确认端口 4768 对应本项目服务，且无运行或排队任务。重启后 `/api/health` 返回 `version: 0.5.0, ok: true`；62 个既有数据文件逐一比较 SHA-256，均未变更或丢失。日志和进程号文件不参与不变性比较。

运行时 `agentConfigured: false, model: null`：本机自主 Agent 的模型尚未配置，不能声称已经能由模型自动规划并执行全部工作。新增对话页使用独立的平台/模型选择，真实密钥和供应商模型也未验证。

用户当前 Chrome 窗口的控制工具发生本机内核启动错误（`sandbox-exec ... TIOCSTI`），连续两次无进展后停止该路径；因此未刷新用户现有标签。隔离 Chrome 自动化及实际本地服务 HTTP 检查均通过。用户可手动刷新 http://127.0.0.1:4768/ 使用新版。
