# 镜场 Agent 0.19 会话图片创作验收

2026-09-28。对照用户提供的快速入门Q3.9：同页Chat/Image切换、比例/分辨率选择、拖拽/粘贴图片、会话历史。此次使用本机模拟兼容接口与真实PNG，未请求云端服务、未产生费用或安装依赖。

## 实现范围

- 对话页面按模式筛选模型，图片模式提供比例、1K/2K/4K、自定义尺寸及质量。文本描述生成1张图片；最多3张参考图编辑。预设尺寸仍由具体模型决定是否支持。
- 本机上传、拖入和粘贴PNG/JPEG/WebP参考，单图10MB。只上传至本地素材库，确认发送前不请求上游。
- 图片任务只发送当前描述和显式参考。结果保存在会话/素材库，可下载、继续改图、切换文字模式讨论，或放回原画布。生成图片按图片节点应用并保留原描述，重复点击不创建重复节点；任务中心返回原会话。
- 文字与图片共用会话并发保护和请求编号。取消/刷新/重启不自动重新生成。原任务索引缺失可从任务记录收回用户消息和结果；部分结果需确认后使用。Key只在请求中使用，不写入任务和素材记录。
- 后续支持图片的文字对话带上最近20条完整上下文；生成图片按user多模态内容传递。完整备份包括尚未放进画布的会话图片，导入重关联后可继续改图。
- 修正大图片导致桌面发送按钮出屏的问题；图片加载后在未主动滚动时保持查看最新消息。
