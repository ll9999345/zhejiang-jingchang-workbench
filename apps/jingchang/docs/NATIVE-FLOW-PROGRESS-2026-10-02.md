执行器会等待本轮上游完整完成；旧预览和未完成文字不能冒充新结果。若一个 ComfyUI 标量字段面对多份素材且没有选择序号，会在提交该下游之前拒绝，保留上游结果。一次图片兼容接口请求仍只接收已请求的单张结果，没有把异常超额返回当作新的批量功能。

## 新接口

`GET /api/projects/:id/native-flow`

- 不带参数：解析当前保存项目；`nodeId` 仅选择显示节点，返回它的有序输入、素材来源、阻断原因及待生成节点。
- `jobId`：只读取当前项目的画布任务，按原任务快照解释已完成步骤；同时返回快照修订和当前项目修订，不把旧结果拼进已编辑的画布。
- `jobId`、`loopId`、`roundIndex`：只选择指定回合，回合序号从 0 开始。默认不合并循环的不同轮次。
- `executionEnabled:false` 表示这个查询接口不发起任务，不代表所有后端节点都不可执行。
- 不创建任务，不保存项目，不读媒体字节，不查账户，不取密钥，不请求模型。无效编号、外项目任务、缺少结果的完成步骤和不存在的回合明确拒绝。

**此接口仅在新源码启动的服务可用。本轮隔离测试已验证，正式 4768 尚未加载它。** 现有主界面也未增加入口；原生面板的旧阻断标签尚未同步。

ComfyUI 映射可附加 `sourceIndex`，序号从 0 开始，指向源节点当前素材列表中的位置，例如：

```json
{"nodeId":"模板节点编号","name":"image","sourceNodeId":"组节点编号","sourceIndex":1}
```

它只用于上游节点映射，不能与固定 `assetId` 混用。格式、容量、连接关系及素材类型继续检查。现有运行范围同意、云服务逐项预算和发送范围要求保持。

含 `sourceIndex` 或原生细项 `inputOrder.itemType` 的完整工程、所选工作流及原生导入中间包自动使用第27版。v1–v26 保留原语义，低版本不能携带这些新字段；修改版本号降级的文件在创建项目或媒体前拒绝，防止旧执行器忽略顺序或只取第一份素材。
