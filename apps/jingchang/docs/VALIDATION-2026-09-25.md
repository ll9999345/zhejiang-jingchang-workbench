# 2026-09-25 验收记录

版本 0.2.0。本次补齐范围为画布批量操作、全局素材、提示词、可视化本机模型配置、ComfyUI 工作流与任务回收，并修复输入切换丢焦点和手机窄屏布局。

## 已通过

- 23 项 Node 测试：图依赖、分组、复制、数据引用、Agent 计划校验、规则拆镜、生成任务状态、取消恢复不重提交、本机协议与重定向拒绝。
- 核心浏览器回归：项目持久化、WebMCP 工具、剧本拆镜、图片导入、分镜编辑、**真实 FFmpeg 合成及 MP4 下载**、版本冲突、跨源拒绝、刷新恢复。
- 新功能浏览器验收：提示词保存/复用、多选分组/复制/对齐及持久化、全局素材命名分类标签与跨项目复用、模型配置冲突保护、工作流导入/修改参数/批量 seed 递增、结果加入项目、任务中心、模型规划后应用、手机布局。
- 独立任务审查发现的设置覆盖、启动时任务记录写入风险、常见 token 字段过滤不足，均已修补。

## 限制

- 语言模型与 ComfyUI 的端到端测试使用本机模拟 HTTP 服务。没有真实 GPU 模型推理，没有付费调用，没有第三方上传。
- 没有完整检查原站所有登录后功能；不能据此宣称一比一复刻完成。完整缺口见 FEATURES.md。
- 在 ComfyUI 接受提交但返回编号之前断线，无法确定原任务编号。会保留不确定状态提示，不自动重试；用户需先在 ComfyUI 核对队列。
- “停止接收结果”仅停止镜场轮询，已提交给 ComfyUI 的计算可能继续运行，界面有明确说明。
