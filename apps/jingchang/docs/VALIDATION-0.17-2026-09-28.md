# 镜场 Agent 0.17 可编辑图片备份验收

2026-09-28。补齐0.16新增图片编辑功能与完整项目备份的连接；无依赖安装、模型请求、外部素材发送或费用。

## 交付

- 完整备份从项目及已支持的工作流/创作台/会话素材出发，递归收集相关图片编辑记录、原图与三种输出。以成品为新底图形成的多级编辑链也保持完整；不带无关记录。
- 含编辑记录时使用第2版清单；新版本兼容已有第1版包，旧读取器明确拒绝第2版。预览展示记录数量和新增依赖素材。
- 验证编辑参数/计算量、源图存在、输出归属、尺寸、无环依赖，以及实际PNG头、全文件SHA-256和长度。缺失记录不会静默降级成普通成品备份。
- 导入记录和所有媒体均分配新编号，重写sourceAssetId、editId和outputs。导入计划持久化，重试沿用编号；相同记录复用，冲突记录保留并报错。
- 恢复后打开图片编辑器可重放笔画、撤销/重做并另存新版本，不需要源服务在线。导入本身不运行编辑渲染或模型。
