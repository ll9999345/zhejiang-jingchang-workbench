# 0.97 通用数字随机开关

日期：2026-10-03。Infinite Canvas 固定提交 `67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e` 是主要功能基准；这里只新增普通 ComfyUI 与 RunningHub 应用／工作流的数字随机配置，镜场自己处理任务持久化与恢复。没有调用第三方 Agent、付费模型或上传第三方素材。

## 使用

生成工作流 → 配置并运行 → 设置字段表单：把字段控件设为「数字输入」，勾选「允许运行时每次随机」，保存范围与步长。运行表单中可分别切换「每次随机／固定数值」。开启后手填框禁用，关闭后原手填值保留。绑定画布节点会保存该节点自己的选择，不改模板默认值。

云工作流 → RunningHub 应用／工作流 → 数字字段：开启随机能力，设置范围／步长和默认开关。画布绑定允许覆盖每个字段的开关。保存、重开、预览不发送生成请求，也不抽取新值；云端实际执行仍须逐次明确服务、预算及发送范围授权。

只有允许随机且可见的数字输入参与；滑杆、下拉、媒体和 RunningHub 标准模型不自动参与。H3、LTX 和增强使用各自的专用配置，避免两个种子机制同时修改片段。

整数按固定版规则向下取整，随机上限不包含。默认普通范围为0至999999；名字／显示名含 seed、noise、随机或噪时，默认最小值1，上限4294967295，并限制种子上限。浮点由小于1的正步长判定，按步长文本的小数位数四舍五入，最高8位；不吸附步长网格。科学记数法、空值数字转换和异常上限的细节在核心单测中按固定版保持。镜场的表单仍要求有效有限范围和合法固定默认值。

## 真实任务与恢复

每个实际请求的每批次、每字段只选一次，先把字段范围和所有批次值写入任务文件，再提交工作流。父画布在创建子任务前也保存原值，子任务使用同一收据；重复请求编号、中断恢复或服务重建不重新抽取。串行及并行循环每轮分别选择，显式逐轮参数列表只在执行副本中覆盖该字段的随机方式，原节点保持。

任务详情可查看／下载已保存值，区分「已提交」「提交待确认」及「已保存，待提交」。保存数值不能证明上游已接受或完成任务。打开的参数详情在轮询刷新后保留。持久记录缺失／非法或父子记录不一致会阻断执行，不能静默退回固定值或重选。现有进度和灵动岛仍由原任务状态控制器处理。

## 备份

包含新数字随机配置的工程／子图采用 `.jingchang` 第34版；整库含此类模板或画布快照时采用 `.jingchang-library` 第2版。恢复重映射模板编号并保留范围、能力、默认开关和逐节点选择；不启动模型、不携带密钥或执行授权。新格式降级、格式标签与内容不符时拒绝。没有新字段的工程第1–33版和整库第1版继续兼容，标准模型原有范围不会触发不必要升级。

工程／整库备份保存配置和原媒体，不包含整个任务历史。恢复中断运行依赖本工作区原任务文件；需要保存实际选择参数时可从任务详情另存JSON，不能宣称仅导入工程包就能查询旧平台任务。
