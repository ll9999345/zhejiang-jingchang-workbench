# 镜场启动、报错与文件查找

更新：2026-09-27。此文档针对独立的镜场项目；用户提供的 Infinite Canvas 教程用于功能参考，其 `main.py`、3000 端口及 `API/.env` 并不是本项目路径。

## 先按这个顺序检查

1. 页面提示与「任务中心」：查看当前错误、是否已提交、是否有结果。
2. 「API 设置」：地址、图片模型分类、准确模型 ID、参考图支持。
3. 「工作区设置」：本机语言模型；「管理ComfyUI后端」检查本次选定地址。
4. 「本机诊断」：FFmpeg 是否可用、媒体文件是否缺失。
5. 服务商控制台或 ComfyUI 窗口：权限、余额、模型、缺少节点、排队状态。

## 常见问题

| 提示/现象 | 处理 |
|---|---|
| 127.0.0.1 拒绝连接 | 双击项目里的「启动镜场.command」，访问 4768 端口；不要关闭不明占用进程 |
| 找不到 Node.js | 本项目需要 Node.js 22+；不要照搬其他项目的 Python 重装流程 |
| API 模型下拉为空 | 添加平台、填 API Base URL，手动添加或拉取模型，分类选「图片」并保存 |
| 拉取模型失败，但模型 ID 已知 | 有些兼容平台不提供 `/models`；可手动填准确模型 ID |
| API 返回 HTML | 地址可能是网页登录页；使用平台给出的 API 地址（常见带 `/v1`） |
| Key 无效/403 | 检查当次输入密钥、模型权限与平台开通情况；密钥不会保存，每次调用需重新输入 |
| 尺寸或模型不支持 | 改成平台明确支持的参数；程序不会偷偷换模型，也不会自动再次扣费 |
| 参考图不能用 | 启用该模型的图片编辑能力；通用图片接口最多20张PNG/JPEG/WebP，每张≤10MB |
| 网络超时/提交不确定 | 先检查服务商任务和账单，镜场不会自动重试；不能因界面失败认定未扣费 |
| 云工作流绑定版本已更新 | 云配置修改后需在画布节点重新绑定、检查字段映射，再执行；旧运行任务恢复仍使用原快照 |
| 画布恢复要求重新输入密钥 | 云节点密钥不会保存；只查询已有任务，尚未开始的后续节点沿用原授权继续。无任务编号的疑似已提交请求不自动重交 |
| ComfyUI 连接失败 | 到设置→管理ComfyUI后端检查已保存连接；确认所选地址服务启动、网络可达、模型和自定义节点已配置 |
| 局域网地址不能保存 | 使用明确的私有IPv4和端口，并勾选发送范围确认；公网、域名、带密码或查询参数的URL不支持 |
| 换后端后旧任务还连接旧地址 | 这是恢复原任务的行为；新后端没有旧任务编号，不会自动重新生成 |
| 不是 API 格式工作流 | 从 ComfyUI 导出含 `class_type` 的 API JSON |
| ComfyUI 没有输出 | 检查保存/预览媒体节点；仅 latent 或文本输出目前不会作为图片导入 |
| 中断后如何恢复 | ComfyUI 可从任务中心继续查原编号；直接图片 API 不具备上游可查询编号，先核对平台 |
| 回答显示“未完成片段” | 请求中断或达到输出限制；片段保留但不进入后续上下文，可确认后放入画布，不会自动续写 |
| 平台不支持流式 | 取消对话页“逐步显示回答”，下一次新请求使用非流式；先核对原请求，勿因显示失败直接重复扣费 |
| 重启后没有继续生成回答 | 只恢复已经保存的片段，不重新提交或续接模型流；若要继续，按新请求重新检查发送范围和预算 |
| 对话无法带图 | 在 API 设置为当前对话模型启用图片能力；历史图片也会计入本次授权 |
| 画布没有可执行节点 | 选择媒体节点，在本机工作流表单完成参数映射并点击「绑定此画布节点」 |
| 画布上游失败 | 后续节点不会提交；核对原 ComfyUI 任务，不能通过反复运行绕过失败或不确定状态 |
| ModelScope/方舟返回找不到接口 | 检查创作台连接设置中的协议；ModelScope 地址通常以 /v1 结尾，方舟以 /api/v3 结尾 |
| 创作台生成结果未出现在画布 | 任务完成后点击「放入画布」，再从顶部返回原项目；不会自动覆盖已有节点 |
| 工作流输入图片仍是旧文件 | 在 LoadImage / LoadImageMask 字段选择项目图片；留空使用原 ComfyUI 文件名 |
| 创作台保存冲突 | 当前改动留在页面；点击保存状态可另存副本，不覆盖原项目 |
| 图片丢失 | 用诊断查素材文件；从自己的备份恢复，或重新导入。不要清理 data 目录 |
| 另一个窗口已更新 | 重新打开项目/平台设置再编辑，避免旧窗口覆盖较新的内容 |
| MP4 合成失败 | 检查 FFmpeg/ffprobe、分镜画面关联、素材格式；生成接口和本地视频合成是两个步骤 |

## 文件位置

所有路径均相对于「镜场Agent」文件夹：

| 内容 | 路径 |
|---|---|
| 双击启动 | `启动镜场.command` |
| 服务入口 | `server.mjs` |
| 本机设置 | `data/config.json` |
| 平台/模型分类 | `data/api-platforms.json` |
| API Key | 不保存到文件，仅在本次请求中使用 |
| 独立对话与历史 | `data/conversations/` 和其 `history/` 子目录 |
| 创作台参数与历史 | `data/studios/<创作ID>/studio.json`、`history/`，通过 projectId 关联主项目 |
| 裁剪与抽帧中间文件 | `data/media-tools/`；正式结果在素材库 |
| 项目与历史 | `data/projects/<项目ID>/project.json`、`history/` |
| 媒体与索引 | `data/assets/<素材ID>`、`<素材ID>.json` |
| 工作流模板 | `data/workflows/` |
| 任务与生成记录 | `data/jobs/` |
| 提示词 | `data/prompts/` |
| 本地视频导出 | `data/renders/` |
| 服务启动输出 | `data/server.log` |
| 独立验收数据 | `artifacts/`（部分单元测试使用系统临时目录） |

备份创作成果时完整保留 `data/`，项目 JSON 导出不含媒体。恢复前先保留现有数据的副本，本程序不自动删除损坏文件、素材或历史版本。


## Gemini / APIMart（0.6）

- Gemini 没有返回图片：确认选择支持图片输出的模型，而不是普通文本模型。原请求可能已计费，先核对平台记录；工作台不会自动重发。
- Gemini 模型列表不全：显示平台本次返回的一页，页面会提示；可在模型ID栏手动输入。列表出现不代表该模型支持图片生成。
- APIMart 模型被拒绝：当前图片支持 gpt-image-2 / gpt-image-2-ext，视频支持 doubao-seedance-2.0 / doubao-seedance-2.0-fast；不会把其他模型硬套入相同参数。
- APIMart 视频本地参考图无法提交：当前该适配只接公网HTTPS参考链接，不自动上传图床。需要本地首尾帧可选择方舟协议并配置其 API。
- APIMart 查询中断：从历史任务恢复原编号查询。没有任务编号时先核对平台记录，不要连续点击生成；停止本机查询不等于取消上游费用。

## RunningHub 云工作流

- API 地址填写平台根地址（不附加 `/v1`）；国内/海外 Key 与地址需匹配。应用 ID 与工作流 ID 不能混用。
- 拉取字段后密钥自动清空，运行或恢复时重新填写。这里只保存参数配置，不保存密钥。
- 上传失败先检查格式和大小。可把媒体字段切换为平台已有文件名；公网 URL 是否可用取决于目标工作流字段含义。
- 已拿到任务编号：到云工作流历史中「按原编号继续查询」。只查询原任务并接续下载，不重新上传/生成。
- 未拿到编号：先在平台核对任务和账单，不自动重发。不支持的输出格式会报错，已经下载的结果保留。
- 配置在 `data/cloud-workflows/`，修订在其 `history/`，任务仍在 `data/jobs/`，结果仍在 `data/assets/`。只有本地模拟与浏览器链路通过，不代表真实账户已开通权限。

## 完整备份

- 「项目JSON」不含素材；换电脑请选择「完整项目备份」。`.jingchang` 只用于镜场，不是ZIP，也不能当作 Infinite Canvas 私有包导入。
- 备份缺少素材：先在资产库找回原文件；不会导出一个假装完整的空壳。
- 文件损坏/校验失败：重新复制或导出原包。校验失败不会新建项目和素材。
- 超过512MB媒体：按项目拆分；不改写原始素材以强行缩小。
- 导入后不能生成：备份没有模型文件、插件、API密钥和本机服务设置。先配置目标电脑的生成服务。导入后的云接口仍需单次授权。
- 导入后的对话可以继续，但旧生成任务、任务恢复编号和项目历史修订不迁移。公网参考图地址可能过期。
- 数据位置：导出包在 `data/bundles/exports/`，接收副本在 `data/bundles/imports/`，恢复后的项目/素材在原有 projects/assets。所有文件保留，不自动清理。

## 工作流字段设置

- 修改范围后旧节点报错：重新打开该节点的工作流绑定，调整参数并再次绑定。隐藏字段不能保留旧的覆盖值。
- 下拉无法保存：默认值必须是选项之一；数字选项应写数字，每行一项。
- 滑杆无法保存：填写最小值、最大值和正步长，默认值须落在刻度上。
- 批次未提交：检查递增后的最后一个seed是否超过已配置最大值。没有任何批次会因这个错误先行提交。
- 表单配置冲突：另一窗口已保存，重新打开以读取最新设置。原API图不变，旧字段配置保存在 `data/workflows/history/`。

## ComfyUI 音视频映射

- 看不到文件选择器：打开「生成工作流 → 配置并运行 → 设置字段表单」，将目标字符串字段的「字段用途」设为图片、视频或音频并保存。字段映射随工作流模板保存；恢复旧备份后也会带回该设置。
- 素材不在下拉列表：先加入当前项目，并检查格式、文件类型和大小。LoadAudio允许视频输入用于读取声音；没有音轨的视频会被ComfyUI拒绝。
- 任务提示文件找不到：ComfyUI输入文件可能被移动或重启环境后丢失；原任务恢复不会重新上传，先检查其输入目录。
- 提交前报输入类型不符：检查字段用途、节点实际需要的媒体类型、上游结果类型及固定素材类型。图片≤10MB，音视频≤150MB，总量≤300MB。映射仅适用于接收字符串文件名的节点输入。
- 取消后恢复：只查询原prompt_id，已完成的素材映射保留；没有编号的任务不能假装恢复，以免重复生成。

## 画布连接与快捷菜单（0.14）

连接需要一端为输出、另一端为输入。拖到同类端口或空白不新增连接；红色落点代表无效连接。形成循环、连接自己或已有同向连接时会提示原因。Esc可取消正在拖动的连线。

右键菜单只在画布内启用，输入框和媒体播放器保留浏览器原菜单。复制整组会同时复制内部连线和工作流动态输入引用；只复制下游时不会补出外部连线，执行前需按期望重新连接。移出画布及移除连接均可撤销，不删除媒体文件。

## 宫格图片（0.15）

「每格至少需要一个像素」表示行列数、边距或间距超过原图可用范围，请减小参数。奇数尺寸切分后格子可相差一个像素，这是保留全部可用像素的正常结果。

拼图宽高由列数、每格尺寸、边距和间距共同决定；超过大小限制时缩小每格尺寸或分批处理。选择「留边」可保留原图内容，「裁满」会裁去边缘，「拉伸」改变比例。背景`#00000000`为透明，`#ffffff`为白色。

处理完成后在全局素材库查看新图片；「全部放入画布」创建新节点，可一次撤销。关闭处理窗口不等于取消处理；中途服务器停止不支持恢复同一次操作，已经保存的输出仍保留。原图片不被删除或覆盖。

## 图片编辑（0.16）

红色只是重绘区域的预览，不会画到结果图片里。需要正常上色时选择「画笔」，希望恢复原图时用「擦除笔画」；清空重绘区域不会清除画笔内容。

扩展边界产生透明区域，实际补全内容需要合适的重绘工作流与模型。透明重绘输入可选LoadImageMask的alpha通道；独立黑白遮罩应选red通道。把不透明黑白遮罩按alpha读取会得到空遮罩。

如果提示编辑过于复杂，先保存已有结果，再以结果图片作为新的底图分段操作。素材库中结果默认重新打开已有记录；保存结果面板的「以成品开始新编辑」可把成品当作新的底图，不再重放旧笔画。记录/原图丢失时无法继续原有笔画；成品PNG仍可正常使用。从0.17导出的新完整备份会迁移已关联的原图与编辑步骤；更早的备份只有成品PNG，可作为新底图。

## 编辑记录备份（0.17）

如果备份提示「缺少图片编辑记录」或「缺少原图」，需要恢复相应`data/image-edits/`记录或`data/assets/`文件，不能仅凭成品还原笔画。备份中素材数多于项目资产时，增加的是继续编辑所必需的原图及各阶段输出。

新备份提示版本不支持时，请使用镜场0.17或更新版本导入。中断后再次确认导入会使用同一计划，不反复创建项目；若提示编辑编号被占用，会保留现有记录，应检查冲突后再处理。

## 全景预览（0.18）

「请选择宽高约为2:1的等距柱状全景图」表示输入不符合全景格式。普通照片或方形图片无法完整表示360°空间，不能仅拉伸尺寸获得真实全景。截图最大单边4096，最多约838万像素，超出时减小宽高。

保存的视角需要保留原全景图才能继续转动；仅有截图PNG不能还原被截掉的视野。完整备份会带齐已关联原图，含全景视角的新包需要0.18或更新版本。原图丢失时请从备份恢复，不要把截图当作原全景替换。

关闭窗口会停止预览；已开始的后端截图可能继续保存至素材库，关闭窗口不会删除结果。

## 会话内图片创作（0.19）

图片模式看不到模型时，到API设置将模型加入「图片」分类；使用参考图还需启用该模型的参考图支持。尺寸预设被平台拒绝时，改用该模型文档支持的尺寸或auto，不要反复提交试错。

上传/拖入/粘贴只是保存到本机并加入当前参考；发送时才会向已确认平台提交。通用图片创作最多20张图片参考，文字模式最多20份图片/视频，其中视频最多3份。点击「继续改图」后还需要填写本次修改要求。

返回文字模式后提示图片输入能力不足，通常是最近会话包含生成图片，请选支持图片输入的对话模型，或新建纯文字会话。刷新后任务显示中断时不会自动生成第二次；同步接口未提供可恢复编号，应先核对上游任务/账单。成功保存的图片仍留在素材库和会话。

## 提示词列表（0.20）

「列表项数须与批量次数一致」时，重新切换到列表方式，让数量按列表自动计算。每行模式会忽略空行，多段文字属于同一项时请使用JSON数组，例如`["第一行\n第二行", "另一个镜头"]`。

列表只能写入一个文字字段，不能把图片文件名列表当媒体映射，也不能同时向同一字段传递上游文字。隐藏字段和下拉选项仍受模板约束。全部项先验证，某项违规会阻止整个批次提交。

中途停止后，「仅取回已完成项」不会补交后续请求。继续原任务会先查询已提交编号，再执行未提交项；最终回填会跳过之前已取回的素材。没有原任务编号的未确认项不能自动恢复，请先核对ComfyUI队列。

画布列表节点之后的下游只接收首份结果。需要每条提示词完整走过多个节点时，添加0.21循环节点并选列表方式；不能通过在图上连成环来代替。

## 多节点循环（0.21）

- 「下游没有已绑定的生成节点」：把循环节点连到媒体节点，并为媒体节点绑定ComfyUI或RunningHub工作流。仅连接空素材框不能执行。
- 「列表循环内至少一个节点须绑定上游文字字段」：在工作流绑定中选自动传递上游文字；RunningHub选择上游文字映射。
- 「嵌套」或「同时属于两个循环」：将两条循环链分开，不能共享下游生成节点。
- 总次数超限：轮数乘以循环体内各节点的批次数，加外部节点次数，合计不得超过64。每个循环最多32轮。
- 每轮图片完全相同：重复模式不改变提示词；工作流也可能按相同种子缓存。开启递增种子，或改用列表。
- 中途停止：从任务中心继续原画布任务；RunningHub重新输入剩余步骤的本次密钥。已完成步骤可先取回，恢复后仅加入尚未取回的结果。没有原编号的不确定提交不会自动重做。

## 每轮不同的参数（0.22）

- 没有可选字段：先连线并绑定下游ComfyUI工作流。图片/视频/音频输入用媒体映射，不在逐轮参数中出现；隐藏字段或已由上游文字/列表控制的字段也不会重复列出。
- 选择不到seed：目标节点开启了递增种子。若要手填每轮种子，先关闭它。
- 值数量不符：轮数改变后检查每个参数的所有轮次；服务端要求值数与轮数一致。
- 某轮超范围或选项无效：没有提交任何一轮，改正后重新开始即可。
- 移动了连线或替换了绑定工作流：原字段可能不再属于循环体；重新选择参数或从循环配置中移除该参数。

## 图片接口自动执行（0.23）

## 语言模型画布执行（0.24）

## 本地合成、声音与字幕（0.26）

## 图片角度 / 导演机位

- 没有文字或图片字段可选：请导入包含可编辑文字输入和 `LoadImage.image` 的 ComfyUI API 工作流，在字段设置里公开对应字段。普通布局 JSON 或仅输出 latent 的工作流不能替代图像编辑工作流。

## LTX 导演时间线

- 找不到导演节点：导入ComfyUI的API工作流，并确认它包含`class_type: LTXDirector`；普通图片/视频工作流不能仅改名称替代。
- 提示缺少LTXDirectorGuide：参考图需要对应Guide读取同一导演节点的`guide_data`。在ComfyUI中配置模型和正确连接后重新导出。
- 时间片段重叠：同一轨道暂不支持重叠，移动或裁短片段；画面与声音可以同时存在。拖动到冲突位置会回到原位置。
- 音频超出素材时长：音频源入点与片段长度合计须在实际素材内。片段起点是它在生成时间线的位置，两者不同。缩短音频片段或换更长素材。
- 实际提示词数量不对：局部提示词不能包含`|`。空隙沿用相邻段提示词；输出帧数是本次生成的截止位置，之后的片段仅保存在配方。
- 删除上游后无法运行：原导演配方保留，在媒体片段中重新选择一个相连上游或固定素材；这不会删除已有结果。
- 任务完成但没有视频：检查SaveVideo等输出节点和模型是否成功。当前本机模拟验收只能验证工作台协议与任务流程，实际LTX运行需对应模型、自定义节点、ComfyUI和可用GPU。


## 增强 / 放大（0.29）

- 没有增强工作流：先在 ComfyUI 装好自己所需的模型与节点，再导出 API JSON 并在增强面板导入。镜场不会自动下载 GPU 模型。
- 强度字段为空：选择原值是数字的强度控制字段。固定基准 Z-Image-Enhance 使用 FloatConstant.value；KSampler.denoise 已是计算连线，不应直接覆盖。

- 4K 结果并非宽高都4096：4K 是短边目标，长边上限4096；保持比例后会缩小。对比页显示的是实际返回的尺寸。
- 停止后继续：任务中心打开原画布任务，使用“继续原画布任务”。已有任务编号只查询，不重新提交；提交结果不确定时先核对上游。第二步失败，可先取回第一步结果。
- 对比原图缺失：恢复包含增强来源链的第4版完整备份；仅导出结果 PNG 不含来源记录。本机诊断可显示缺失文件或原图索引。
- ModelScope 权重报错：LoRA最多6项，权重均大于0且合计为1；单一LoRA写1。它是模型混合比例，不等于本地增强强度。模型/LoRA是否有权限仍取决于账户。

## 对话 Agent 自动创作（0.33）

- 两个模型下拉缺项：对话模型须归为「对话」，图片模型归为「图片」；当前Agent路径使用兼容接口平台。多轮生成历史含图片时，对话模型还须有真实识图能力，并在API设置启用。
- 为什么问答也要确认图片服务：Agent在开始后判断本次任务，发送前列出两种可能使用的服务和上限；只有判定需要创作时才调用图片接口。仅需固定文字回答可选「文字对话」。
- 「内容已变化，请重新检查」：会话、系统指令、模型或参考选择与预览不同，关闭检查框后重新检查。不会据旧预览执行新内容。
- 「没有有效动作计划」：判断模型没有返回约定JSON或返回不支持的动作。未调用图片服务；查看任务阶段，检查对话模型能力。程序不会按关键词自动代为生图。
- 改错图片：当前所选图片优先；未选择时，沿用的是最近一次完整图片结果中的首图，发送检查框会展示。要改其他图片，点对应图片的「继续改图」，或加入该图后选择Agent模式。中断时保留的片段不会自动成为上一张图。
- 改图尺寸不同：明确写出的比例/尺寸优先，其次所填尺寸；沿用历史图且尺寸为auto时继承实际图像尺寸，再按16倍数规范。供应商是否支持此尺寸须由真实模型验证。

- 测试显示成功但没有真实API Key：测试使用伪密钥和本机模拟返回，只验证流程。真实创作需要你自己的有效模型服务及授权；没有Key不代表系统已经连上云平台，也没有自动获取账号密钥的功能。
- 导入备份报版本不支持：含系统指令或Agent记录需要镜场0.33或更新版本。完整备份保留参数/素材关联，不携带平台配置、密钥、生成任务或授权；换工作区后需重新选择可用平台并检查发送内容。

开启「逐步显示回答」但一次显示完整回答，可能是平台返回了JSON，工作台会正常保存同一次回答，不会再次请求。平台错误、无效数据与工具调用仍会报错；显示「未完成片段」时需核对内容，不会自动继续生成或运行下游。保存过接口设置不表示真实账户已接通；当前项目测试只使用本机模拟端点和人工占位Key。

## 已有火山API却仍提示未配置（0.84）

先区分对话Agent和视频接口。agentConfigured:false表示语言模型未配置，与Seedance账号不同。创作台选择方舟视频协议、填入北京官方地址与实际模型ID/ep-接入点，密钥来源可选“使用本机已有火山配置”；画布执行及恢复也有同样选择。

“已找到配置”表示服务端环境变量或钥匙串同名服务项存在，不表示权限/余额/型号已通过真实验证。状态检查不提取密码；执行授权后若钥匙串不可读取，会给出固定提示并停止，不创建生成任务。可检查macOS钥匙串访问，或改为本次填写，不必把密钥发给助手。自定义代理/其他地区/其他协议不能使用这一来源；素材库仍另需AK/SK。

历史任务恢复使用任务保存时的官方地址，而不是后来改过的连接设置。有上游编号时只查询原任务；无编号且状态不确定时先核对平台控制台和账单，不自动重新生成。旧文旅项目曾成功调用Seedance，不代表新镜场的全部素材组合和生成质量已验收。

## 大文件导入与备份（0.85）

- 超过150MiB仍被拒绝：在主素材库导入常见媒体，或在“公网素材链接”窗口选择文件并点击“仅保存到本机”。普通文本/JSON/三维/文档、Chrome采集、生成模型输入仍有原限制，不能因为本机文件已入库就直接发送。
- 提示4GB过大：4GB在此明确为4,000,000,000字节，不是4GiB。所选Litterbox仍限150MiB；切换服务会重新要求预览和公开范围确认，不会自动换站。
- 原文件导入断流：未完成文件不出现在素材库，已接收部分保存在`data/asset-imports/导入编号/original.bin`。读取原记录可看状态；未完成编号不会自动重传。选择再次本机导入会创建新编号，原部分保留，不自动清理。
- 已导入但模型报太大：生成平台的时长、格式、像素、单文件及整个请求容量独立检查。火山素材关联的本机视频检查仍限原150MiB范围；4GB托管不是4GB Seedance参考输入授权。
- 备份提示需要第18版：含超过150MiB常见媒体、FLV或合计超过512MiB普通媒体需镜场0.85及v18。所有文件总量最多4GiB，包含大文件、音轨和原图依赖。旧备份仍可导入，新版不能伪装为旧版。
- 可用空间不足：本机导入、完整备份保存和逐个素材恢复均保留64MiB余量。失败时不覆盖或删除原项目，已收到的部分仍保留；需要自行决定恢复范围或另选空间充足的位置。
- 暂存目录看起来也有一份完整原件：成功导入的暂存原件与素材文件是同一文件的硬链接，未重复复制文件内容。完整备份恢复只携带素材和项目关联，不携带旧的本机导入台账。

- 导出失败：导出范围内每段需要本机视频；入出点必须在实际视频时长内。FFmpeg按项目画幅／帧率拼接裁切区间，保留原素材与项目分镜；失败记录可在任务中心查看。
