# 原生整组素材与三类接口增量

日期：2026-10-02。基于 0.93.0 源码继续开发，没有发布新版本。整体参考功能整合仍未完成。

## 已完成的后端链路

- 原生素材组、生成节点的整组结果、输出接收器，可以作为图片接口、画布语言模型和创作台的参考来源。普通生成消费者取输出接收器最新一项；语言模型按图片、视频、音频分别取最新一项。分组成员及生成细项保留原生排序，包括不同来源之间交错排列。
- 保存的上游节点映射保持不变。计划展开已知素材，按配置估算待生成数量；本轮上游完整完成后，使用其真实输出再次展开与预检。旧预览、未完成结果不能冒充本轮结果。
- 展开后的数量、类型、格式、文件大小和模型能力继续受原接口限制。实际数量超过计划确认的范围、增加未确认的媒体类型，或缺少原视频/音频发送授权时，保留上游结果并停止下游，不截断、不自动去重、不额外发送。
- 原生文本按输入规则汇总；关闭“包含上游文字”时保留节点自己的提示词。语言模型完整回答可传到后续创作台。
- 同步接口提交不确定时仍不自动重发。恢复先查找持久化子任务；即使父任务尚未写下子任务编号，也能按请求编号找回原任务。
- 第 28 版完整备份保存上述接口与原生整组输入的组合语义，恢复后可重新规划，不恢复密钥或执行授权。带新语义的备份不能通过修改版本号降为 v27；既有版本仍按其原有语义读取。
