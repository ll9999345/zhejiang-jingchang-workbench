# Ctrl 拖动连接与循环插入 · 2026-10-27

状态：0.99.24-dev.1 本机候选已实现并通过下述验收，**未切换正式服务**。正式 4768 仍为 0.99.23，V2 未重启。本项不能代表所有参考功能已经完成。

## 功能与用法

- 智能画布中，按住 **Ctrl** 开始拖动节点标题；可连接的目标显示轮廓。松手后增加输入连接并将原节点复位。Ctrl 在开始拖动时锁定，Cmd 不代替 Ctrl。
- 单独拖动智能循环，中心距输入/流程连线中点不超过 96 个画布单位时显示粗虚线；松手将原连线替换为“上游 → 循环 → 下游”。保留原上游边的 input/flow 类型，下游使用 input；循环启用与轮数仍由用户设置。
- 单独 Ctrl 拖动图片到已有多图卡片，合并素材、迁移连线并保留选定素材字段。进入智能分组的吸收逻辑优先于自动连接；循环插入优先于入组。多选不会自动连线。
- Ctrl 操作、位置与原生输入次序通过现有 `/api/projects/:id/smart-groups/reconcile` 一次保存。保留撤销、版本冲突和回执恢复；取消拖动不提交。操作指南新增说明。
