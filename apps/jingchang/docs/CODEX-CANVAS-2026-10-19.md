# 0.99.14 · Codex接入画布语言节点

开发日期2026-10-19；验收跨至2026-10-20。原入口：选中文本或剧本节点 → 绑定语言模型 → 执行方式 → **本机Codex · Responses文字与看图**。上一轮独立任务页、原API方式与已有数据保留。

本轮把已接通的Codex执行器接入原画布按连线运行流程，不是把界面中的名字改成Codex。实际使用已安装的官方CLI0.147.0，经本次受限本机转发器访问已绑定的Responses服务，至多一次模型请求；平台API Key不传给CLI、不保存。没有复用既有CLI登录账户、接入第三方Agent或进行付费生成。

## 使用

1. 在原API设置保留/建立支持Responses的OpenAI兼容对话服务及模型；图片需要明确启用模型的图片能力。普通Chat Completions可用不代表本模式可用。
2. 选中文本或剧本节点，打开“绑定语言模型”，选择执行方式、平台快照、模型、系统指令、输出上限、上游文字及图片参考。保存绑定不执行程序或调用模型。旧绑定未设置执行方式时保持原API方式。
3. 使用原“按连线运行”检查步骤。Codex步骤会显示本机程序版本、程序和入口文件指纹，明确服务、模型、文字、图片、次数和预算。逐节点填写本次Key与正预算并确认；程序或入口变化后必须重新检查，不沿用旧确认。
4. 开始后只向已确认服务发送一次，完整普通回答进入当前运行副本，并可作为下游语言或生成节点的输入。不完整/不确定/停止时保留原收据与片段，后续不提交，不自动补写或重发。
5. 完成后用原“加入画布”取回。普通画布保留原提示，新建结果节点；等待期间有新编辑时继续按原版本保护处理。部分未完成文字不作为完整生成结果回填。
6. 服务重启或流程中断后，用原任务中心读取/继续。继续只读取已存在的Codex原收据，完整旧回答可供后续流程使用；没有完整回答时停止，不重跑该CLI或模型。尚未启动的后续节点仍须原有逐节点授权与瞬时Key。

原生提示词、相连文字、整组图片引用及循环采用现有画布计划规则；循环每轮为独立确认的步骤和请求，不偷带上一轮旧回答。多路智能串联/原生cascade调度器的能力不因普通画布接入而自动扩大。

## 持久化与恢复

父画布任务 → 原canvas-llm语言子任务 → 不可变codex-chat原调用记录。语言任务的codexTaskId在启动CLI前持久化，CLI编号从语言子任务编号确定；父子归属由服务内部校验，HTTP请求不能传入内部工程/平台快照来扩大执行范围。

本机CLI仍受操作系统文件/进程/网络限制，只读本次资料、写本次目录、连接本次端口，不使用Shell、MCP、网页或子代理。停止父任务会中止本机CLI及转发等待，不等于平台取消或保证未计费。

CLI原文先持久化，再交付工具；服务重启不执行工具，读取原完整回答后恢复语言摘要与父任务流程。正常运行时，原结束记录存在但摘要还未写完的短时间里继续显示运行，收尾完成后才显示终态。接口只读查询不重发模型，也不写回语言摘要；启动恢复才按原收据修复缓存。

“导出全部留痕”的.jhistory同时保存父流程、语言子任务、CLI原输入/程序/授权/回答与原图片。恢复为新项目后仅只读，不安装活动任务或账户。档案校验父子关系、程序指纹、服务快照、输入、引用、授权、次数和原回答；重算档案SHA不能绕过这些对应关系。原过滤器遗漏的语言模型能力列表及语言步骤字段已补齐，其他未知字段仍拒绝声明完整。

## 容量和边界

沿用语言节点最多8张PNG/JPEG/WebP图片，每张10MiB；Codex图像原字节合计18MiB，已知固定输入预先检查，实际动态结果发送前再检查。文字最大32000字符、系统指令16000、输出上限128–8192；完整结果最多20万字。Codex不处理本模式中的视频、原视频音轨、音频或文档；这些继续使用相应原API方式，不静默丢弃输入。独立Codex任务页仍保留自身20张图/20000字当前问题的限制。

同一本机服务同时最多两份Codex调用等待。当前只验收本机macOS官方0.147.0所安装架构，其他版本、CPU、Windows/WSL和实体手机未验。模型必须支持Responses及对应图片能力，真实云端、看图质量、权限、计费与GPU尚未验收；预算是发送授权记录，不是供应商强制扣费上限。

普通对话中的自动CLI路由、Codex既有登录账户复用与生图、Gemini/Antigravity执行、全参考项目全部功能对照仍未完成。本轮付费及第三方上传均为0。
