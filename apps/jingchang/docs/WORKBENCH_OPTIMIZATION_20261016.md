# 2026-10-16 · 文旅与镜场性能优化

需求来源：省赛提交后继续跑通优化文旅工作台，用户追加镜场也同步优化。

已完成并在本机服务生效：

- 项目库只读取当前阶段，不为卡片解析全部历史版本。完整制作记录仍读取历史和审核轨迹。58项项目摘要逐项相同，三轮交错测量的读取中位耗时由1.4998秒降至0.676秒。
- 共用玻璃渲染器识别SwiftShader/llvmpipe等软件渲染器，在该环境保留原视频背景与CSS玻璃，避免CPU执行实时折射与画面回读。硬件WebGL路径保留。Chrome软件渲染对照采样：长任务总耗时2715ms降至474ms，最长533ms降至66ms。只代表该次测试环境，不代表实体GPU帧率或全设备性能。
- 镜场节点拖动、平移和框选合并至显示帧。松手/失焦先应用最后坐标再保存。切线笔迹仍保留中间采样点。连线布局按节点建立索引并复用节点高度，减少逐边重复查询。
- 镜场低帧率自动暂停只作用于当前页面，不写成永久偏好。旧版保存的auto在重开时重新采样，用户显式暂停/恢复继续保留。
