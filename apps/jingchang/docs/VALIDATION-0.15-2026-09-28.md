# 镜场 Agent 0.15 宫格图片验收

2026-09-28。以用户快速入门Q3.10的「宫格切分」为功能依据，增加本机宫格切分及配套图片拼接；保持自己的实现与界面。没有安装依赖、调用模型、上传第三方或产生费用。

## 交付

- 切分：1–8行、1–8列，外边距与格间距，预览点选格子；从左到右、从上到下输出独立PNG。整数分区保留奇数尺寸余数，跳过用户设定的边距/间距。
- 拼接：1–64张，可重复选同一素材和调整顺序；列数、每格尺寸、外边距、间距、完整留边/裁满/拉伸、RGB/RGBA背景；末行空位和透明图片正确与背景合成。
- 复用严格本地素材读取、显式解码器、尺寸限制与最多两项并发；拼接先校验所有输入，再生成输出。不覆盖或清理源文件。
- 入口：素材库图片的宫格按钮、素材库顶部拼接按钮、画布图片节点属性面板。手机表单和底部保存可操作，小图预览适当放大以方便选格。
- 结果进入全局素材库，可下载、逐项或全部放入画布；批量放入是一次可撤销编辑，刷新仍保留。处理中关闭窗口后不重新弹窗，完成结果留在素材库。
