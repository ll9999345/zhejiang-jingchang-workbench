# 0.70 Alt 拖动复制验收

日期：2026-09-30

依据 Infinite Canvas 固定提交的画布交互，新增 Alt 拖动复制。拖动单个节点会复制该节点；拖动已选多节点会复制整份选区；若完整复制一个已有分组，则副本保留组名标记、颜色、成员关系和组内连线。拖动结束后副本保存为项目修订；一次撤销会同时移除副本节点、分组和连线。局部选中组成员时不复制原组元数据。

验收结果：

- `node --test tests/canvas-tools.test.mjs`：13/13 通过，包括完整组复制和部分选中不影响原组。
- `npm run test:canvas-alt-drag`：通过。隔离浏览器验证复制整组与内部连线、偏移位置和项目保存、一次撤销整体删除；3 项浏览器断言通过。
- `npm run test:canvas-interactions`：24 项画布浏览器检查通过，覆盖移动端画布右键菜单、连接、分组、复制、对齐与撤销。测试先关闭遮挡画布的输入面板，再检查手机视口中的菜单定位。
- `npm test`：352/352 通过；`npm run check` 与两个浏览器脚本的语法检查通过。
- 浏览器验收使用独立临时数据目录；没有连接 Astra、读取 API Key、请求真实模型、上传素材或发起付费任务。

本次只实现 Infinite Canvas 固定版的一项画布交互，不代表其全部能力或其他参考 GitHub 仓库已完成；Photoshop 连接器、协作/共享及其他未核验功能仍存在差距。
