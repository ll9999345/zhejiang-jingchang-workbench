# 0.99.12 · 原版提示词 JSON 互通

日期：2026-10-19。入口：[镜场整合工作区](http://127.0.0.1:4750/canvas) → 提示词库 → 库与分组管理。本轮仅本机文件操作，没有付费生成、真实模型调用或第三方上传。原有项目、回收内容、版本和默认追加方式保留。

## 导入 Infinite Canvas 文件

1. 在原项目找到 `data/prompt_libraries.json`，保留原件。
2. 镜场提示词库管理 → **备份与恢复** → 选择原版 JSON → **本机检查备份**。
3. 先看库名、分组、条目数、反向词和参数建议数量。此时尚未建立新库；也可点“下载导入原文”核对。
4. 勾选“确认建立新编号……”再恢复。镜场建立独立新编号，不覆盖当前库。同份接收记录重复确认不会再建立副本；若重新选择文件重新接收，则明确作为另一份独立导入。
5. 回到“提示词”，选择导入库。名称、正向词、反向词、适用场景、平台参数建议和原来源资料一起保留；跨库相同条目/分组编号不会互相覆盖。

支持根对象 `{active_library_id,libraries,updated_at}`，以及单层 `{library: ...}` 包装。不会扫描电脑、自动读取其他目录或执行文件中的命令、脚本和参数。缺少声明但被引用的分组会补全；结构损坏、同库重号、不支持的超限内容、可疑凭据资料会明确拒绝，原文件保持。

## 三种使用方式

- **使用提示词**：保留原默认行为，将正向词追加到节点正文，将反向词追加到排除内容；有变量时先填写。
- **更多使用方式 → 替换为正向词**：替换所选节点正文，不改模型设置，支持撤销。
- **更多使用方式 → 替换为整套文本**：将正向词、`Negative prompt:` 和 `Params:` 组成文本替换正文；这些参数只是文字参考，不会变成模型配置。支持变量填写、撤销。

没有选中节点时创建文本节点。以上操作都不会触发生成。老编辑器会保留未显示的参数建议；版本恢复也会恢复当时的建议。参数建议与原来源资料目前只读展示，编辑正文、反向词和适用场景的入口不变。

## 两种备份

**镜场完整备份**：导出全部库或当前库，保存当前内容、回收内容、已有版本和来源资料。包含新资料时使用自身 v2 格式；原无新资料的 v1 仍可读取。恢复后继续使用新编号，不覆盖现有资料。此备份不包含原接收记录与字节级原文，要保留原文件应另外“下载导入原文”。

**原版 JSON 副本**：展开“导出为原版 Infinite Canvas JSON”，选择全部可用库或当前库 → 检查范围 → 阅读差异 → 勾选确认 → 下载。原版格式不保存镜场的回收站及版本历史，本次只导出可用内容的当前版本。它会按原版规则处理名称、编号、首尾空白与未分组条目，预览列明差异；镜场原资料不变。原版程序可能丢弃扩展字段，因此完整保存请保留镜场备份和导入原文。

检查之后若目录或内容改变，下载会拒绝并要求重新检查。下载只保存本机文件，不上传。原版项目整套运行及其特定部署版本仍需在实际原项目验收，本轮只运行固定版真实纯解析函数验证字段兼容。

## 中断后继续

恢复期间关闭服务或异常退出，尚未整体提交的条目暂不显示。重开管理器 → 备份与恢复 → 读取接收记录 → 核对原记录并重新确认恢复，继续同一固定映射，已写好的副本不重复。不会启动时自动恢复，更不会调用模型。

## 文件与接口

- 全局目录：`data/prompt-catalog.json`；模板：`data/prompts/`；接收原文与恢复计划：`data/prompt-catalog-imports/`。不要把这些文件覆盖到原版项目目录。
- 旧 `/api/prompts` 的编辑及历史记录增加 `recommendations` JSON；旧编辑客户端不传该字段会保留现值。
- `POST /api/prompt-catalog/imports`：`{requestId,sourceText}` 原文优先，亦保留 `{requestId,manifest}`。只检查和接收，不恢复。
- `GET /api/prompt-catalog/imports/:id/original`：已接收的原版文件原文 UTF8 下载，附 SHA256；自身备份记录不伪造原版原文。
- `GET /api/prompt-catalog/native-export/preview?libraryId=`：只读返回差异报告和指纹。
- `GET /api/prompt-catalog/native-export?fingerprint=...&libraryId=`：指纹匹配后下载原版副本，否则409。原文/副本使用二进制下载类型，防止整合入口改写JSON内部文字。
- 4750整合入口只改写真正媒体资源地址，不修改 `recommendations`、`nativeSource` 内的资料网址。

## 容量与验证边界

原版文件最多8MiB、100个库、单库200组、10000条；正/反向各20000个JS字符，场景500字符，名称120字符，建议64KiB、单条来源资料256KiB。镜场备份32MiB，目录12MiB，单条最多200版本；超限明确拒绝，不静默截断导入资料。原文本下载保证本轮支持的有效UTF8 JSON文字逐字节一致，不保证任意编码、重复JSON键或损坏文件的无损解析。

本轮验证：24项相关自动检查、旧提示词12项浏览器回归、旧目录5组/新互通4组真实本机浏览器流程、原版纯解析函数契约、真实HTTP强制终止恢复和真实V2路由转发。所有写入都在隔离测试目录；正式界面只读检查。手机/低动态/旧机是Chrome模拟，不是实体设备验收。原版预设全文没有随程序复制安装；自身十条示例为独立文案。其他参考功能、真实账号/GPU/云端生成质量及账单仍未全部验收。
