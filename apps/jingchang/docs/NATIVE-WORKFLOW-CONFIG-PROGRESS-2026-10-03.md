# 0.98 原生字段配置和逐节点参数迁移

日期：2026-10-03。基线：0.97.0。整合目标仍进行中，付费生成及第三方素材上传继续暂停。

## 本轮功能

- 导入 ComfyUI API 图时可配对 Infinite Canvas `.config.json`。保存字段编号 `nativeFieldId`、目标节点/输入、文字/布尔/数字/下拉/媒体控件、类型化默认值与数字随机能力；未配置的输入保持隐藏原值。
- 已有模板可从“导入原生字段配置”读取文件或粘贴，先检查映射再明确保存。检查只做本地转换，不写文件、不连接后端、不执行下载代码；保存新增修订并保留旧字段。检查期间换文件/内容，旧返回结果不能用于保存。
- 显式选择本机模板后，普通 ComfyUI 的 `comfyParams` 和 `comfyRandomActive` 按原字段编号恢复。智能素材读取 `runSettings`（兼容旧 `comfy_params`）；原智能画布的整数控件按 `Math.round` 转换，浮点保持。固定值、布尔勾选、滑杆和逐字段随机状态填入表单，绑定后保存到该节点。
- 普通 RunningHub 应用/工作流可本地导入 `fields` 或 `nodeInfoList` 字段配置，包括 `fieldData` 的 LIST index 选项。原节点参数按真实的 `nodeId::fieldName` 双冒号键匹配。节点可独立覆盖数字/文字/开关/选项值，原云配置默认值不变；随机字段继续使用 0.97 的每批原值记录。
- 画布预览/执行使用节点覆盖的配置副本；字段不能同时固定覆盖和映射上游。原任务恢复沿用已保存的固定值及随机收据，不读取后来改过的模板/云配置，不重复提交。
- 包含原生字段编号或云节点固定覆盖的工程/子图使用 v35；整库使用 v3。旧版本没有新增数据时继续兼容；伪装为旧版本的新增数据拒绝。模板、云配置、画布及对应编号在恢复后重新关联，当前画布保留。

## 操作入口

1. 画布左侧“生成工作流”→导入 API 图，可选同名 `.config.json`；或打开已有模板→“导入原生字段配置”→检查→保存。
2. 导入原生画布后，选择待迁移节点→“重新绑定本机 ComfyUI 工作流”→选模板→核对显示的原值及随机开关→绑定→在检查器明确确认迁移。
3. 顶部“云工作流”→普通应用/工作流→展开“导入原生 RunningHub 字段配置”→检查→采用→保存。该入口不拉取平台、不需要密钥。
4. 选择原生云节点→绑定云工作流→核对逐节点覆盖值与随机开关→保存→明确确认迁移。保存绑定不启动生成。
5. 普通云节点也能勾选“覆盖本节点”，未勾选时沿用云配置原值；检查器/任务清单会展示实际值与随机范围。

## 数据和验收边界

- 不按外部工作流文件名、平台编号或字段标题猜测对应关系；用户须明确选择本机模板/云配置。无法匹配或随机能力冲突时显示原因并阻止保存迁移绑定。
- 原媒体文件标识只列为待核对，不自动成为本机素材。提示词角色、媒体来源及上游映射仍须按当前表单明确设置；本轮不宣称自动还原全部原生提示词/媒体行为。
- 配置 `title`、`mini_cards` 以及其他原配置展示元信息未迁移成镜场布局。原生节点原始 JSON 继续保留；已配置节点不能伪装导出为原生可执行包。
- 本机模板已有的字段类型、范围、步长校验保持；无法对应或无效的字段定义清楚拒绝。未支持的动态/复杂配置不静默降为成功。
- RunningHub 标准模型和 H3 使用各自专用表单，本轮通用固定覆盖不替代它们。
- 工程/整库不打包执行历史、API 凭据或执行授权。原平台任务查询依赖原工作区任务文件。
- 实体手机、旧机和真实云账户/模型/GPU/账单未验收。浏览器手机宽度与降级模拟、合成回环协议、真实本机进程重启分别记录，不能等同这些外部验收。
- 所有参考项目完整能力、嵌套/分支、反馈/退出、自动重复处理等缺口仍未完成。
