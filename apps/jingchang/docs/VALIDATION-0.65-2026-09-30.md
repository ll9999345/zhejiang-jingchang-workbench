## 实现

- 资产卡片提供单图“智能分类”，只接受 PNG/JPEG/WebP、最大 10 MB。
- 用户须选择已保存的 OpenAI 兼容视觉对话模型，并明确同意向页面显示的服务 origin 发送当前图片和可选补充说明、最多提交一次。远程服务另要求填写本次预算和 API Key；本机 HTTP loopback 可留空密钥与预算。
- API 密钥仅随当前请求传输，不写入平台设置、图片、分类结果或日志；服务端限制模型、origin、图片数量/类型/大小与授权字段。不存在已配置模型时引导去 API 设置，不自动接入任何默认模型或第三方 Agent。
- 解析结果规范化为描述、分维度标签及关键词，存到对应素材元数据；分页资产库可按智能分类筛选，并搜索分类标签。
- 请求失败且结果可能不确定时提示先核对平台任务与账单，不自动重试。预算是用户授权记录，平台仍可能按自己的计费规则扣费。
