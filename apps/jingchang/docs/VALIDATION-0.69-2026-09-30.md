# 0.69 提示词库版本与变量验收

日期：2026-09-30

本轮为提示词库补上版本历史、本机变量填写和可选的 AI 改写。编辑会按 `revision` 追加快照；旧版恢复也会新增一版，旧数据读取时虚拟兼容为 v1。列表只返回版本数，用户打开历史时才读取完整快照。每条提示词最多保存200版；到上限后拒绝继续写入，不会静默丢弃历史。`{{hero}}` 变量由页面表单本机替换，不调用模型。AI 改写由用户逐次确认，只向用户设置的本机模型地址提交一次；返回草稿后用户可修改、取消或进入版本编辑器，系统不自动保存或重试。

验收结果：

- `node --test tests/prompt-library.test.mjs`：4/4通过，覆盖编辑版本、过期修订冲突、恢复为新版本、旧格式读取、变量替换及错误输入边界。
- `node --test tests/prompt-rewrite.test.mjs`：2/2通过，使用本机 mock 服务验证单次提交、不发送认证头、未同意时零提交、非本机地址拒绝和错误不重试。
- `npm run test:prompt-browser`：12项浏览器断言通过，使用独立临时数据目录及隔离服务，实际完成保存模板、填写并追加变量、未同意时不调用 mock、单次本机改写、预览后保存 v2、恢复旧版并生成 v3；页面无脚本错误。
- `npm test`：351/351通过。
- `npm run check`、`npm run check:prompts`：通过。
- 更新后的本机服务健康检查显示 `version: 0.69.0`；没有调用真实模型、读取密钥、上传素材或发起付费请求。

未以真实 Astra/供应商服务验证改写效果；本轮使用的仅是本机 mock。提示词库这部分不代表所有参考 GitHub 项目功能均已完成。Chrome 扩展尚未在用户的 Chrome 安装验收。
