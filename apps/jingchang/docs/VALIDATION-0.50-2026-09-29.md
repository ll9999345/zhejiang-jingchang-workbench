# 0.50 验收记录：画布与素材库媒体预览

日期：2026-09-29。验证使用隔离临时数据目录和本机模拟素材，没有访问真实模型服务。

## 实现

- 点击画布节点或素材卡片中的图片可打开大图预览；视频保留卡片内原有播放控制，并提供单独的放大预览按钮。
- 生成批次内按该次任务的结果顺序浏览；普通导入素材按项目顺序浏览。支持左右方向键、前后按钮及手机横向滑动；到达首尾会循环。
- 显示原图像素尺寸及画布节点关联的提示词，可一键复制提示词。
- 从预览打开素材所属节点的编辑面板，或点“重新生成”打开节点原有的生成授权表单；必须由用户继续完成现有单次预算、密钥和同意步骤，按钮自身不提交任务。
- 支持下载当前原文件、按 Esc 或点击遮罩关闭，并把键盘焦点还给打开预览的缩略图/按钮。
- 预览层使用对话框语义，限制焦点在预览层，并适配手机视口。
