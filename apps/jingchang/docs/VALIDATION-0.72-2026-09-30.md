# 0.72 图片 API 遮罩重绘验收

日期：2026-09-30

把本机图片编辑器生成的黑白遮罩接入画布图片 API。遮罩必须在当前项目中、由本次选中的同一张底图生成，并与底图解码后尺寸相同。底图和遮罩在内存中统一转成 PNG；遮罩编辑强度写入 alpha 通道，保留区域不透明，重绘区域透明。请求使用 `/images/edits` JSON `images[].image_url` 与 `mask.image_url` data URL 形式，单次固定生成一张。

模型遮罩能力默认关闭；只有 OpenAI 兼容图片模型、已启用参考图，且用户核对供应商文档后，才可在 API 设置开启。云端请求还要求本次同意发送遮罩。项目记录只保留素材编号及授权范围，不保存 API Key，也不自动重试不确定的生成请求。

验收结果：

- `node --test tests/image-api.test.mjs tests/direct-images.test.mjs`：19/19 通过，覆盖 JSON data URL、单字段长度限制、PNG 校验、单底图限制、灰度到 alpha 转换、来源和项目归属、模型能力保存、遮罩发送授权以及密钥不落盘。
- `npm run test:image-api-browser`：通过。真实 Chromium 表单完成平台配置、底图编辑、遮罩选择和单次 mock 提交；检查请求为 JSON、重绘区 alpha 为透明，切换到不支持遮罩的模型会清空遮罩选择，并验证项目任务、移动视口、诊断及素材归档恢复。无页面异常。证据位于 `artifacts/image-api-qa-1790714251222/`。
- `npm test`：357/357 通过；`npm run check` 通过。
- 本机服务重启前查询无运行任务。浏览器测试使用隔离临时工作区与本地 mock；未调用真实模型、云平台、Astra 或计费接口。

范围限制：OpenAI 官方图片编辑文档规定 `images` 和 `mask` JSON 图片引用。其他 OpenAI 兼容代理是否支持该格式需逐家确认；遮罩选择框默认关闭，不代表模型实际具备遮罩编辑能力。真实模型画质、费用与云端兼容性尚未验收。无限画布其他未核对差异和其他 GitHub 仓库的逐项功能仍未完成。
