# 0.54 验收记录：画布提示词 `@` 图片引用

日期：2026-09-29。参考 Infinite Canvas 固定提交 `67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e` 的教程说明。本地完成自有实现，没有复制上游实现代码。

## 实现

- 在画布普通节点的提示词中输入 `@`，可搜索并选取全局素材库里的本机图片，无需为固定参考图手工建立连线。
- 引用上限为每节点20张；仅接受不超过10 MB的 PNG、JPEG、WebP 图片。选择、移除、项目保存和完整备份保留资产关联。
- 图片引用会进入图片API、兼容的多模态语言模型、创作台、ComfyUI及RunningHub规划；工作流仅在存在唯一空闲兼容字段时自动映射，不猜测多个候选字段。
- 引用图片仍受上游接口、模型和工作流真实能力限制。真实第三方服务的参考图行为尚未验收。
