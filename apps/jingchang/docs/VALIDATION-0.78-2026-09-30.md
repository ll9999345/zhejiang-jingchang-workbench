# 0.78 验收：原视频理解与混合素材确认

日期：2026-09-30。

## 本轮交付

- Gemini 普通文字对话与文本/剧本画布节点可明确选择「原视频」输入。默认仍为画面抽样；模型的原视频能力默认关闭，须在 API 设置中按模型文档开启。
- MP4、WebM、MOV 原文件在本机检查，预览显示实际时长、尺寸、文件大小和是否含音轨。每份原视频不超过10MB；整个 Gemini 编码请求不超过18MB，包含系统指令、历史和其它素材。MOV 使用 `video/quicktime`。
- 图片、视频抽样、原视频及声音、独立音频和提取后的文档内容共用发送确认。原视频在本机播放器中预览；当前或历史含原视频时必须单独确认发送范围，不因选择模型或切换模式自动发送。
- 原视频作为 `contents.parts[].inlineData` 随一次 `generateContent` 请求内嵌发送，没有单独上传远端文件。此路径完整返回，不提供逐字流式回答。
- 历史逐条保留原来的抽样或原文件方式；新一轮改变方式不重写旧消息。恢复页面时补取本机素材类型，避免音频历史误显示为图片。
- 画布支持固定、相连上游已有和本轮生成原视频；生成后校验实际文件，只有完整回答才传给下游。片段或未知结束状态停止下游，原任务恢复不自动重新提交同步对话。
- v13 完整备份携带原视频会话记录、校验信息和画布选择，导入后重映射素材编号并可继续。旧版 v1–v12 支持保留，原有未设置输入方式的语言绑定不被强制写入新字段。

## 真实验收边界与剩余差距

全部模型请求使用合成媒体、测试密钥和本机隔离模拟服务，没有使用用户API Key、访问真实Gemini或其他模型平台、执行付费调用或上传用户素材。本地请求、播放和恢复检查不证明真实模型权限、音视频理解质量、报价或兼容代理可用。

原视频尚未支持远端Files API、大文件、更多格式、YouTube或公网链接、视频输入的原生流式响应及未知响应部件上下文。模型能力由用户依据实际模型文档配置，不从模型名称自动猜测。

其它GitHub参考仓库尚未逐仓逐功能验收；RunningHub三维/真人资产、方舟更多参考与AK/SK素材库、APIMart更多模型/本地视频素材、条件/反馈/嵌套循环、CLI任务和真实云/GPU验收仍有缺口。整体功能整合目标未完成。

本轮是镜场新增的原生协议能力。固定版 Infinite Canvas 的 `/api/canvas-llm` 主要使用兼容协议和视频抽样，不据此宣称上游已具有相同的Gemini原视频会话。协议字段和格式依据：[Google 视频理解文档](https://ai.google.dev/gemini-api/docs/generate-content/video-understanding)。
