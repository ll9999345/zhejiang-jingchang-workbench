# 镜场 0.99.24 正式本机交接

证据与归档日期：2026-10-31。来源：用户持续整合要求及为答辩保留过程。项目：原生镜场Agent，V2仅同步文档与只读检查。状态：本次版本已发布，本地范围已验收，整体整合继续。

## 本次交付

0.99.24 将此前隔离候选中的 Ctrl 拖动和指针粘贴带入正式入口。按住 Ctrl 开始拖动单个智能节点，可连接兼容目标并回到起点；图片拖到图片卡片可合并，智能循环可插入邻近连线。先前的组合测试覆盖 Alt 复制、取消、多选与历史卡片排除，不能扩大为全部组合已验证。

复制镜场内节点后，将指针放在画布位置再粘贴，选区原点中心对齐指针；重复操作各有独立编号，支持撤销。切换工程且未移入新画布时采用视图中心。跨工程操作保留原生关系、素材引用及持久化记录；网络成功响应丢失可读取原记录，不重复创建节点。

新增能力参考 Infinite Canvas 固定提交 67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e，沿用其非商业/署名自定义许可归因，非MIT。上游纯计算片段用于隔离对照，没有执行第三方Agent。界面及现有配置保持原有项目方式。

## 使用与恢复

刷新 http://127.0.0.1:4768/ 或V2画布入口后使用新功能；旧页面同规则的保存仍兼容，新增快捷操作需加载新脚本。当前程序选择在 runtime-selection.json；原0.99.23完整快照保留。不要手动恢复旧业务数据或整目录覆盖，后续回退继续使用受控交接工具检查当前进程和活动任务。

实现工具：JavaScript ES Modules、Node.js 24.18、Pointer Events、SVG、串行操作队列、持久化回执、原生节点身份映射、node:test、Playwright、Chrome for Testing 150、FFmpeg/FFprobe、SHA-256。Codex用于编程与检查，本轮未调用生成模型制作素材。
