# 画布语言节点接入本机Gemini（2026-10-21）

本机正式服务已更新0.99.19，4750整合入口只读验收通过。保留原API与Codex绑定，增量接入已有Gemini独立任务与原收据，不接入第三方Agent。

## 使用方法

1. 在工程画布选中文本或剧本节点，打开「绑定语言模型」。执行方式选择「本机Gemini」，平台仅显示Gemini原生服务。未配置服务时先添加平台与普通对话模型。
2. 配置系统指令、输出上限，以及「当前节点与所有上游文字」或「仅当前节点文字」。参考素材可使用固定PNG/JPEG/WebP或相连上游图片节点。此执行器暂不发送视频、音频；它们可继续使用原API方式。
3. 保存绑定保留平台快照，之后平台列表变化不会偷偷改用别的服务。程序暂未核对或版本变化会在本机运行检查时拒绝，未发送至模型。
4. 点击画布运行，先看节点顺序、提示词、参考图、程序版本/指纹和实际服务。每个待运行节点分别填写本次Key、正预算并确认一次请求，再确认整条画布运行范围。Key只用于本次内存，不写入节点、任务或原收据。
5. 本机Gemini得到完整普通回答后才继续下游。下游语言节点使用本轮已完成的文字；片段、失败或结果不明会保存原收据并停止，不自动重发。
6. 完成后明确「放入画布」产生结果节点，保留原提示词和人工新编辑。重复放入不会增加副本。停止整条画布会停止其本机子等待，不代表上游已取消。
7. 服务中断后读取原收据。若当前节点回答已持久化，明确继续只执行剩余节点，不重新调用已完成节点；片段与结果不明不会自动重发。完整.jhistory保留父画布、语言包装任务、Gemini原任务、输入/程序/授权及回答，新工程导入只读，不安装活动任务。

## 代码与技术

复用`canvas-llm.mjs`、现有画布执行器及Gemini任务服务。增加Gemini原生执行方式、平台筛选、程序证明、逐节点确认和父子任务连接。绑定平台快照可独立于当前平台目录；运行前复核实际程序与图片原字节。沿用0.99.17的macOS隔离/一次性本机转发和0.99.18的原任务体系，未读取个人CLI登录、Jio、Pro或Flow权益。

完整执行输入支持画布原有1–32000字，区别于独立任务页新问题20000字上限；25k中文实际请求逐字比对；从此长输入的原任务继续独立讨论，也保留完整问题及图片，不受旧历史问题20000字限制，仍受10万字和18MiB总量限制。重复引用同一张大图只计一次原文件字节，但保留两条映射；全部图片和完整编码请求继续受实际容量检查约束。动态上游结果在执行时重新校验，超出类型、数量或已确认范围会停止。

Node.js ES Modules、原生HTML/CSS/JavaScript、SHA-256、既有Gemini CLI0.51.0/macOS sandbox-exec、Playwright/Chrome for Testing150、FFmpeg/FFprobe。没有安装依赖或系统软件。固定Infinite Canvas基准67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e为自定义非商用/开源署名条件，不是MIT；本轮运行代码独立实现，已有Gemini CLI程序为Apache-2.0。
