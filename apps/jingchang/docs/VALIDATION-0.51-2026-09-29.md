# 0.51 验收记录：输出组批量下载

日期：2026-09-29。浏览器和项目数据均使用隔离临时目录中的合成图片。正式服务只做健康状态/任务列表只读检查，没有生成任务。

## 实现

- 预览属于同一次生成任务或画布分组、且至少包含两份图片/视频时，显示“下载本组”。项目素材库的普通浏览和其他项目的素材不显示该按钮。
- 服务端只打包当前项目已关联的素材；最多100份，展开后总计不超过256 MB。校验素材文件仍是普通文件、大小与记录一致，并拒绝重复编号、无效编号、符号链接和项目外素材。
- 生成标准 ZIP，保留 UTF-8 文件名；重名文件自动加序号。内容直接流式发送，不在项目目录写入临时 ZIP；传输中断时关闭本地文件句柄。
- ZIP 下载只是本地文件整理，不调用模型、平台或 API Key。此前加上的“重新生成”入口仍只打开已有单次生成授权表单。
