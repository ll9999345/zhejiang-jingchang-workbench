# 0.53 验收记录：图片生成参考关联与前后对比

日期：2026-09-29。功能按用户指定的 Infinite Canvas 固定提交核对。本轮没有配置、读取或调用真实 API Key，没有向第三方发送素材。

## 实现

- 图片生成结果回填时，把输出素材编号写进项目运行记录；在本地参考素材确实属于当前项目且为图片时，同时保存输出到参考图片的关联。
- 覆盖 ComfyUI 批量结果、普通图片接口、画布级联步骤、创作台图片任务和 RunningHub 工作流任务。画布级联的每张结果会保留它自己的参考关系。
- 媒体预览在存在本地参考图时显示“生成前后对比”；对比窗口支持选择参考图片与拖动分割滑块。
- 对比只使用项目中已有图片资产；跨项目编号、远程 URL、视频与音频不会成为对比素材。
- 画布预览批次依赖生成回填写入的 `assetIds`。旧任务若没有保存参考图关联，不会从提示词或文件名推断历史关系。
