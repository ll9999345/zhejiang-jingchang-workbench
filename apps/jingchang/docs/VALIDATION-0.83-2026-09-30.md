# 0.83 本机原文件托管与素材入库连接验收

日期：2026-09-30（Asia/Shanghai）。正式服务版本0.83.0，地址`http://127.0.0.1:4768/`。本轮独立实现临时托管协议与本机记录，不执行上游代码，不连接竞争产品Agent。

## 实现范围

- 画布资产页“公网素材链接”、创作台素材库“公网链接”、火山素材库“从本机文件取得公网链接”。可选择本机图片、视频或音频，按完整原字节发送，包含原有声音，不裁剪、转码或去声音。
- 显式选择temp.sh或Litterbox；预览绑定原文件SHA-256、类型、大小、用途、目的地和预计72小时保留。上传确认包含持链接者可访问的公开范围；后续火山入库、签名查询和生成有各自的单独确认。
- temp.sh使用`file` multipart；Litterbox使用`fileToUpload`、`reqtype=fileupload`、`time=72h`。正式目的地固定，loopback只用于同路径模拟。没有API凭据；发送素材编号文件名，原文件名与本机路径不交给托管服务。
- 202返回后后台执行，按projectId/requestId去重。本机记录显示进度、原结果及预计到期；断流、错误响应、重定向、未知链接和5xx不自动重发或更换服务。打开列表、刷新、服务重启和恢复备份只读取原记录。
- 成功上传记录可填回火山入库表单；入库时检查原文件与上传记录、URL和当前内容一致，保存publicMediaId。只在明确Active后转为typed asset://引用，再经独立生成确认提交与回填。
- v17备份包含公网上传记录、原文件及火山记录的关联。恢复时本机编号与依赖同时重映射，URL及原预计到期不变，标记restored；不恢复授权、不重新上传或延长保留。
- 创作台素材库入口等待当前项目加载完成；上传状态提示跟随本机记录，不继续显示已完成的“正在上传”。

2026-09-30只读核对[temp.sh官方首页](https://temp.sh/)的file multipart、三日保留与4GB平台说明。本轮Litterbox官方网页的工具访问403、浏览器导航超时，未能读取其官方API页面；按用户指定固定源码实现，不能据此承诺真实服务可用。

镜场仍遵循现有150MiB普通素材上限，未实现参考项目的4GB上传范围。托管预览校验的是普通文件与原内容摘要，不证明实际媒体编码；火山关联随后另做既有解码/格式/尺寸/时长检查。72小时为预计保留，ready只表示服务返回格式正确的链接；远端内容、可访问性与后续平台读取均未验证。

未使用用户API Key或AK/SK、未接受外部平台授权协议、未将用户素材发送到真实第三方、未付费生成。真实托管、真人活体认证、模型权限/GPU、更多协议参数和其他参考项目的逐项完整验收仍未完成，不将本轮测试计作“所有功能均可用”。
