# 0.68 验收记录

日期：2026-09-30  
范围：补齐 Chrome 网页素材扩展中用户明确选择后的导入并智能分类流程，依据 Infinite Canvas 固定提交的 [Chrome 扩展说明](https://github.com/hero8152/Infinite-Canvas/blob/67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e/tools/chrome-local-asset-importer/README.md)。

## 实现

- 扩展连接本机服务后，只读取适用于图片输入的已保存 OpenAI 兼容对话模型清单；该清单不包含 API Key，CORS 只给镜场扩展开放目录与单素材分类路由。
- 修复扫描计数更新但结果行未写入列表的问题；扫描到的素材现在能正常看到并勾选。导入期间禁用重复提交，避免同一批次误触发重复模型请求。
- 智能分类默认关闭。用户选模型、在扩展弹窗临时填写本次 Key（外部模型）、单张预算记录和币种、勾选本次图片发送同意，并点击“导入并分类所选”后，才分类已导入图片。
- 只发送 PNG/JPEG/WebP 且不超过 10 MB 的图像；每张至多发起一次分类。其余已选图片仍可保存在本机。
- 第一次分类请求失败后停止本批后续分类，不自动重试；剩余素材继续本地导入。弹窗关闭或本次处理结束时密钥不写入浏览器存储、项目或扩展日志。预算是明确授权记录，不是服务商实际扣费上限。
