# Gemini CLI 文字与看图接入（2026-10-21）

状态：本机正式服务已更新至 0.99.17，4750 整合入口只读验收通过。整项 Gemini CLI 与全部参考项目的功能整合尚未完成。

## 使用入口与步骤

工程 → 设置 → 本机工具 → Gemini 文字与看图任务。也可在选中文本节点后进入，带入原稿和取回目标。

1. 在 API 设置保存 Gemini 原生服务和普通对话模型。图片理解须明确启用模型的图片输入能力。
2. 选择服务、型号，填写问题、可选系统指令和参考图片。可以明确沿用此前完整返回的本机讨论。
3. 点击「本机检查发送范围」，逐项核对实际问题、历史、图片、模型服务和已检查的本机程序。此步不调用模型。
4. 真正发送时填写仅本次使用的 API Key、服务、预算和一次请求授权。远端至少填写 0.01 的明确预算；该数值记录授权，不是平台扣费上限。此次开发验收没有实际远端发送授权，也没有执行云端生成。
5. 原回答保存后可下载文字、另存文本节点，或取回原节点。原节点有新编辑时拒绝覆盖；重复取回同一位置不会增加副本。
6. 「读取原记录」、重启服务、刷新页面、停止等待及档案导入都不会自动再次请求模型。停止本机等待不代表远端取消。

## 实现范围

- 本机已安装 `@google/gemini-cli` 0.51.0，未安装、升级或登录另一个程序。执行前比较完整程序目录、依赖和 Node 的指纹。
- macOS 本轮独立执行器；Antigravity、其它版本、其它操作系统保留原有状态入口，未核实执行能力时拒绝运行。
- 子程序仅能连接一次性本机转发端口，不能读取个人文件、执行 shell、使用 MCP、扩展、工具或遥测。真正的服务密钥不交给子程序，不保存到任务、项目或浏览器存储。
- 转发端以确认后的快照重建 Gemini 原生请求：系统指令、按顺序的历史文字、当前问题和图片原字节。忽略子程序携带的替代输入、工具与系统指令；锁定已批准型号和路径，最多转发一次。
- 最多 20 轮、10 万字、20 张 PNG/JPEG/WebP，每张不超过 10MiB，完整编码请求不超过 18MiB。重启后不重发结果不明的请求。
- 请求原计划、提交、回答、程序结果、停止及结束分别持久化。`.jhistory` 保存原输入、程序指纹、图片校验、一次请求授权和回答，导入只读，不安装活动任务。
- 保留现有画布入口和普通 Gemini API 对话。主画布 `app.js`、保存保护模块不作替换。
