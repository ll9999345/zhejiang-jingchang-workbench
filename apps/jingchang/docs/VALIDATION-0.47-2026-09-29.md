# 0.47 验收记录：类型化连线与媒体参考映射

日期：2026-09-29。验证对象为本地隔离工作区；未打开或更改正式项目数据。

## 实现

- 画布端口显示节点能输出和接收的文字/媒体类型提示。
- 新连线检查节点存在、自连、重复、依赖环、嵌套循环，以及已绑定图片接口、语言模型和创作接口的媒体输入类型及容量。
- 兼容的直连媒体连线会写入目标接口的动态参考列表；图片接口只接收图片，多模态语言模型最多 8 张图与 3 段视频，创作接口按图片/视频操作校验输入。
- 移除连接时一并清理依赖此连接的动态参考、ComfyUI媒体字段与RunningHub字段映射；固定素材引用保留。撤销/重做恢复连线与映射快照。
- ComfyUI 和 RunningHub 的字段由用户明确选择，避免猜测首帧、尾帧或多个条件媒体字段的用途。
