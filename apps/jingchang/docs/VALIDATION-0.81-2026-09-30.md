# 0.81 验收：方舟 Seedance 2.0 多素材参考

日期：2026-09-30。实现与检查范围为本机协议、界面和持久化；没有真实云端生成或账号验收。

## 本轮交付

- 创作台与画布新增显式 `arkReferenceMode:multimodal`。旧配置缺少此字段时仍为 `frames`，原首帧/首尾帧语义不变。多参考按原顺序使用图片、视频、音频各自的参考角色，不混入首尾帧角色。
- Seedance 2.0 系列最多9张图片、3段视频、3段音频；至少一张图片或一段视频。本机图片支持PNG/JPEG/WebP，音频支持MP3/WAV；视频原文件只使用公网HTTPS或平台asset编号。HTTPS不接收凭据、查询参数和私网地址，平台编号仅在多参考模式接入。
- 本机预览检查文件与记录、符号链接、实际解码、图片尺寸/比例、音频单音轨/时长/合计时长、编码后发送大小。预览不创建生成任务或读取外链；外部格式、时长与权限明确标为未核实。工作台的文件与48MiB请求限制比平台允许范围更小。
- 生成前显示素材列表和已知尺寸/时长；视频或音频原文件及其声音需要单独确认。原字节内容发生变化时原确认失效，重新预览后才可发送；失败不自动重发。
- 画布保存有序媒体类型和来源，支持静态/动态图片、音频以及外部视频；静态内容在父子步骤之间复核，动态输出在实际发送前检查。停止/服务重启后仅查询原编号、下载原结果，不重交或再次读取参考文件；结果可回填共享主画布。
- 完整备份扩展为v15，保留多素材模式、类型、平台编号，并重映射本机文件ID。旧v1–v14仍可读取；伪造旧版本携带新参考语义会明确拒绝。
- 验收修复了共用检查模块在浏览器中的加载路径；正式画布已实际打开并显示3个原节点，连接错误为false。
