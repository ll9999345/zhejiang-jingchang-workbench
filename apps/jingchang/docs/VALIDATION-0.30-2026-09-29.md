# 0.30 RunningHub 标准媒体模型与账户查询验收

日期：2026-09-29。当前本地服务为 `http://127.0.0.1:4768/`，版本0.30.0。该项补齐专用模型流程，不代表整个参考项目已全部复刻，也不代表已完成真实云端生成。

## 已交付

- 云工作流增加标准模型类型，按媒体类型/关键词筛选，离线加载官方固定目录和参数。含422个目录项，349个媒体型号可配置；文字、三维和6个需独立资产转换的媒体型号不可运行。
- 参数支持整数、浮点数、布尔、单选、多选、文字列表、尺寸，以及有序图片/视频/音频参考。字段、必填、范围、图片总像素与尺寸优先级由服务端校验。Qwen 的 LIST 数量选项保持字符串，Speech 的发音词典保持数组，符合官方接口示例。
- 运行预览显示实际编译参数，包括型号要求的提示词比例前缀。素材先检查归属和类型，再经专用v2上传接口上传；重复素材只上传一次，各槽位仍保留顺序。
- 标准型号使用专用v2提交接口，共用原任务号查询、停止、服务重启恢复、部分下载恢复、结果入库和回画布。应用/工作流原有接口保留。
- 图片/视频/音频节点均可绑定相同输出类型的标准模型，接收上游文字及匹配媒体，沿用每节点/每轮授权。完整备份第5版保留型号、目录版本、参数和本机素材关联；导入重映射配置/素材编号。
- 账户余额、RH币和当前任务数查询；缺值显示“未返回”，查询密钥及账户结果不落盘。
- 新建、切换和保存配置期间锁定表单，避免异步加载覆盖刚输入的地址；旧请求不回写到已切换配置的任务区域。

## 排错与证据限制

一轮浏览器测试暴露了新建配置的加载竞态：输入的测试地址被默认平台地址覆盖。该轮只使用合成素材和虚拟密钥，在上传阶段失败，生成提交计数为0；没有使用用户素材或真实账号。现已修复加载期间表单锁定，并为相关浏览器验收进程增加`tests/helpers/local-network-only.mjs`，阻止任何非本机网络目标。表中三个通过的浏览器验收均在该限制下重跑；同时校验运行前的实际目标地址。

正式页面的Chrome截图接口连续两次返回“Unable to capture screenshot”，未把截图算作通过。正式服务以浏览器DOM、只读接口、页面错误和写请求检查验证，截图采用隔离验收环境的实际页面，分别保留证据。
