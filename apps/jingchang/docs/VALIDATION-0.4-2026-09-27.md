# 0.4 整合验收记录

日期：2026-09-27。GitHub Infinite Canvas 为功能基准，Miao 仅作交互参考。本轮没有复制上游实现，没有接入其 Agent，也不宣称全部功能对齐。

## 已完成的整合

- 创作台关联主项目，主画布、分镜、剪辑可往返；创作台结果加入同一项目和素材库，任务中心按主项目归属显示。重复回填不重复创建节点，版本冲突不覆盖已有编辑。
- 连接设置复用主画布已保存的图片平台和模型分类；不保存密钥。新建项目、保存、切换、撤销、小地图、平移和手机面板已验收。
- 图片 1/2/4 张、最多4参考图、质量、尺寸、透明背景；指定协议的异步图片和视频生成/编辑/延长、查询、结果下载及恢复。不确定的提交保留原请求编号，不自动重发。
- 视频估价按秒、图片按张；预算独立填写且必须为正。一次多图请求仍是一次提交。预算不是上游扣费的硬限制。
- ComfyUI 的 LoadImage / LoadImageMask 可选择当前项目图片；全部输入先校验，单图≤10MB，同一图片多字段和多批次只上传一次，恢复查询不重复上传或提交。
- 本地图片裁剪和视频指定时间抽帧使用真实 FFmpeg，原素材保留，结果可下载、入库、放回画布。
