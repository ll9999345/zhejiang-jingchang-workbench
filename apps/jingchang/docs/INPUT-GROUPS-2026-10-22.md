# 镜场0.99.21 · 创建输入组与生成连线交接（2026-10-22）

本轮补齐固定普通画布的输入组创建和交接路径；原视觉编组继续保留。输入组全部生命周期尚未完成，已有组的成员增删、跨组重归属和拖入自动入组仍待补齐，不能将本轮写成完整输入组复刻完成。

## 使用

1. 在画布选择图片、文本或剧本，选区工具条点「创建输入组」；也可从添加节点菜单进入。默认混合组汇总适用的图片和提示词，提示词组仅纳入文字。其他类型在检查页列为未纳入。
2. 输入名称，先「检查创建范围」。显示成员、未纳入数量、将替换的组员生成连线及下游节点；检查本身不新建组、不生成、不上传。
3. 明确确认后，使用原工程版本保存。混合组将成员已有的普通生成连线交给新组，其他连线、原节点/位置/文字/素材、视觉分组、任务及明确字段映射保持。提示词组按源独立创建语义不自动交接，可手动拉输出端口到目标。
4. 组头拖动会整体移动组及成员；透明外框不会挡住内部节点的编辑。复制和移出选中的输入组会包含其成员，原素材文件保留；一次撤销/重做恢复原图与原连线。选区工具条挡住节点标题时，可先Esc取消选区，再打开节点编辑。
5. 「检查输入 / 输出」复用原数据流面板，可查看整个组的提示词和图片；原运行前检查复用组成员依赖，明确字段映射仍可指向组内原成员。需要模型时仍由原运行确认逐服务、预算和素材范围授权，创建本身不发请求。
6. 空组可保存并连接，但当前为空不传递内容；目前没有在原组上增删成员的入口。要建立有内容的输入组，请先选择尚未归属原生输入组的图片和文字。若选区仅包含一个视觉组的部分成员，会提示先选整组，不拆改原组。已有原生组成员不会被默默移走。

## 排错留痕

旧原生浏览器脚本最初缺少originalWidth字段映射，被现行校验阻止绑定；在隔离测试模板中补齐明确nativeConfig映射，再通过完整13组。没有放松运行时校验、丢弃原参数或把初次失败标成通过。失败截图和日志均保留在阶段目录。
