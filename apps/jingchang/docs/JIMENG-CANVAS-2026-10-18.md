# 2026-10-18 · 画布节点接入即梦任务与受保护回填

本轮将已存在的本机即梦任务页接入主画布节点，正式本机版本为 **0.99.6**。主要功能基准仍为 Infinite Canvas 固定提交 `67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e`；本轮为镜场自主实现，没有调用 LibTV 或 RunningHub 的 Agent。

## 使用方法与实际行为

1. 在镜场画布选择图片或视频节点，在右侧点击“用即梦生成此节点”。进入前保存当前画布，避免丢失刚输入的文字。
2. 带入当前已保存的上游提示词、目标节点文字和本机参考素材。原生分组顺序保留；两张视频参考默认按顺序列作首帧、尾帧，仍须核对角色。不会运行上游生成节点，也不会把生成节点的旧输出自动当作自身参考。
3. 检查即梦模型、比例、时长、分辨率和参考列表。带入的是当前输入，模型采用即梦默认值，不将其他平台的模型名静默转换。超出命令能力的素材/规格不截断或静默降档，需要明确修改。
4. 点击“本机预览本次范围”。预览绑定原节点及依赖的内容指纹；它不执行CLI、不上传、不消费积分。若需切离原节点，先点“改为独立任务”；“重新带入节点”会替换未提交设置。
5. 真实生成仍需用户另行给出明确服务、预算和发送范围并确认。付费生成继续暂停，本轮没有操作这一步的真实平台；截图中的提交/查询仅运行隔离的本地可执行测试程序。
6. 完成后可选“回填绑定节点”，保留节点文字、参数和原素材，同时在旁边保存结果节点。若原节点、依赖或连线已改动，拒绝覆盖；可明确选择“另存新节点”，保留新旧内容。相同结果已另存或回填后，再次操作不会重复建节点或再次改写原节点。

## 实现与持久化

- 新增 `lib/jimeng-canvas.mjs`：复用原生数据流解析已保存的文字/媒体，计算节点、依赖和连线的SHA-256内容签名。普通画布移动和无关新节点/新素材不会使原范围失效。
- 任务计划增量增加可选 `canvasTarget={version:1,nodeId,nodeType,signature}`；只保存绑定标识和摘要，不复制整个画布或原始节点。未绑定的旧任务结构和指纹保持原样。
- 预览、确认及执行意图写入前均核对范围；本机素材复制也校验原文件指纹。按原编号查询仍单独确认，重启不重提、不自动查询。
- 回填在项目互斥保存区核对最新修订及目标范围。原生图片、生成器、智能素材、视频的资源映射与媒体列表同步更新，原素材和原始参数保留；旧项目不重置。
- `.jhistory`携带原绑定签名、生成与查询收据，但恢复为只读历史，不安装活动任务、不自动执行CLI。
