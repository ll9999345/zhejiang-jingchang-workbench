# 0.59 验收记录

日期：2026-09-29  
范围：固定版 Infinite Canvas Chrome 素材采集器的多选下载路径。依据的上游提交仍为 `67f49e4b9a0ac090bad1f5bd62ae385f8fb5394e`；本实现独立编写，不复制上游源码。

## 实现

- 选中单份素材时直接下载原文件；选中多份时按网页标题生成 `<网页标题>.zip`，并在压缩包内放入同名目录。
- ZIP 使用 UTF-8 文件名、CRC-32 和不压缩存储；同名文件按大小写不敏感规则递增编号，拒绝绝对路径、`..`、非法路径字符及空文件。
- 每批最多 40 份，所选文件内容合计最多 256 MiB；超限或读取失败项显示原因，其余有效文件仍可打包。此上限避免浏览器一次保留过多素材。
