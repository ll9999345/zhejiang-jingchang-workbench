# 智能组操作候选 · 2026-10-25

状态：磁盘候选 `0.99.23-dev.6`，尚未发布。正式4768及V2代理4750仍为0.99.22；本轮未重载。只有隔离验收服务显式启用 `JINGCHANG_SMART_GROUP_MEDIA_TEST=1`，才开放智能组界面和服务接口。不可直接开启个人工作区来代替兼容验收。

## 本轮补齐的操作

- 从选区创建智能组。图片收进组内网格，原图片卡片退出当前画布；提示词、循环继续作为独立成员。素材文件和项目资产不删除。
- 在检查器中加入图片或合并另一个智能组，保留未知图片元信息、原生文档头、未引用资源；改接已有连线、按种类去重并移除自环。
- 解组释放自身网格图片，原成员留在原位置；可单独释放一格或移出成员。整理、尺寸表单与整体移动服务已实现。
- 网格按组内顺序预览，可用键盘切换与下载组内原文件。修复点击图片时画布重绘打断预览；组背板置于普通卡片下层。
- 编辑前预览下游已选素材字段。对于各轮都能确定为同一原文件的字段，保留原文件身份；尚未生成、序号不明确或各轮不同的字段阻止保存，不自动换图。不同工作流中同名素材路径在合并时重新建立本机资源映射，防止误选第一张图。
- 一次保存使用修订号、预览摘要与请求编号；丢失响应后只读取保存回执，不重发。不同窗口同时修改只接纳一份。页面撤销/重做恢复组结构和对应字段。
- 新增智能组编辑回执校验与只读归档字段，工程包、原生ZIP和任务档案跨目录恢复通过。

## 候选使用方法

1. 在隔离候选画布选择图片、提示词等卡片，点击选区工具条的「创建智能组」。填写名称并检查修改范围，确认后保存。
2. 选中组，在右侧「加入 / 合并」勾选卡片或另一组，先看素材字段保留说明再保存。
3. 使用组内图片右上角按钮释放一格；「解组并释放素材」将自身图片恢复为独立卡片，提示词等成员保留。
4. 「整理组内」「调整尺寸」「整体移动」也先预览，再保存。可用撤销/重做恢复这一项本机编辑。

旧导入文件若本来把图片成员摆在组上方，会保留其原坐标，仍可能视觉重叠；键盘可以选中。吸收后收进网格。本轮不把原布局自动重写成新布局。

## 接口

`POST /api/projects/:id/smart-groups/preview` 与 `/apply` 仅在候选能力位 `smartGroupLifecycle=true` 时开放。请求仍受素材页面会话核对约束。支持 `create / absorb / release / release-item / detach / arrange / move / resize`。

共同字段：`mode`、`revision`、`requestId`；非create需`groupId`。创建、加入、移出需唯一`nodeIds`；创建需`title`；单格释放需`index`；整体移动需`x/y`；尺寸需`width/height`。可提供本机测得的`rects`。apply必须携带preview的`planHash`。回执保存在`settings.smartGroupEditReceipt`，包含保存修订、摘要和选区编号。

预览不写项目、不调用模型；保存后增加一个项目修订。并发冲突或预览已过期返回409，原文件保持。相同请求及摘要返回已保存版本，不重复编辑。
